1 Invertible operators

Let \(V\) be a linear space. An operator is a linear map from \(V\) to itself. If \(V\) is equipped with a norm (i.e., \(V\) is a normed space), then \(\mathcal{B}(V)\) denotes the space of bounded operators.

An operator \(T\) on a vector space \(V\) is called invertible if there exists a (linear) operator \(T^{-1}\) such that \(TT^{-1} = T^{-1}T = I\). For \(T^{-1}\) to exist, bijectivity is necessary. But is it sufficient for \(T^{-1}\) to also be linear? One can prove that it is sufficient (in general this is not obvious! check it yourself). Hence an equivalent formulation of invertibility: an operator \(T\) is invertible \(\iff\) \(T\) is bijective.

Further, if \(V\) is a Banach space (i.e., a complete normed space) and \(T\) is a bounded operator that is also invertible (i.e., bijective), then \(T^{-1}\) is not merely linear, but is also bounded (i.e., \(T^{-1} \in \mathcal{B}(V)\)), by the theorem on the bounded inverse. This fact is itself not obvious, be aware of it! In particular, if \(V\) is merely a normed space (incomplete, i.e., not Banach), then \(T^{-1}\) need not be bounded, even if the operator \(T\) is bounded and bijective.

ExampleExample 1

Give an example of normed spaces \(V\), \(W\) and a bounded map \(T: V\to W\) such that \(T\) has an inverse map \(T^{-1}\) (which is, accordingly, linear) that is not bounded.

SolutionSolution

  • \(V\) and \(W\) cannot both be Banach, otherwise by the theorem on the bounded inverse \(T^{-1}\) would be bounded. Let \(V = (\ell^1, \left\| \cdot \right\|_{1})\), \(W = (\ell^1, \left\| \cdot \right\|_{\infty })\). These are the same linear space, but different normed spaces.

    Let \(T := I\), i.e., the identity map.

  • Sidenote: \(V\) is a Banach space, since we take \(\ell^1\) with the standard norm (this is the Riesz-Fischer theorem). \(W\) is not Banach. Indeed, let

    \[ f^{(n)} := \left(1, \frac{1}{2}, \frac{1}{3}, \ldots , \frac{1}{n}, 0,0,\ldots \right), \qquad n \in \mathbb {N} \]

    The sequence \(f^{(n)}\) lies in \(\ell^{1}\) and is Cauchy in the sup norm. However, it has no limit in \(\ell^1\): in \(\ell^{\infty } \supset \ell^{1}\) it converges (in the corresponding sup norm) to \(f = (1,1/2,1/3,\ldots )\), but \(f \not\in \ell^{1}\).

  • Is \(I: V \to W\) bounded? Note that \(\left\| f\right\|_{\infty } = \sup_{n \in \mathbb {N}}\left\{ \left|f_n\right|\right\} \leq \sum_{n=1}^{\infty }\left|f_n\right| = \left\| f\right\|_{1}\). Hence

    \[ \left\| I\right\| = \sup _{\left\| f\right\| _{1} = 1} \left\| f\right\| _{\infty } \leq \sup _{\left\| f\right\| _{1} = 1} \left\| f\right\| _{1} = 1 \]

    Thus, \(I: V \to W\) is bounded: \(I \in \mathcal{B}(V,W)\).

  • Is \(I: W \to V\) bounded? Let

    \[ f^{(n)} = (\underbrace{1,1,1,\ldots ,1}_{n \text{ times}},0,0,\ldots ) \]

    Note that \(\left\| f^{(n)}\right\|_{\infty } = 1\) for all \(n\), but \(\left\| f^{(n)}\right\|_{1} = n \to +\infty\). Consequently

    \[ \left\| I\right\| = \sup _{\left\| f\right\| _{\infty } = 1} \left\| f\right\| _{1} = +\infty \]

    \(I \not\in \mathcal{B}(W,V)\).

Lemma 1 (Norm of a composition of bounded maps) Let \(U,V,W\) be normed spaces, \(T \in \mathcal{B}(U,V)\), \(S \in \mathcal{B}(V,W)\). Then \[ \left\| ST\right\| \leq \left\| S\right\| \cdot \left\| T\right\| \]

Unlike linear maps from one vector space to another vector space, operators on one and the same vector space can be composed with themselves and raised to powers. Namely, if \(T\) is an operator on a vector space \(V\), then

\[ T^{k} := T \circ T \circ \cdots \circ T, \quad k \in \mathbb {Z}_+ \]

In particular, \(T^{0} := I\) is the identity operator. Check for yourself that powers of an operator satisfy the usual arithmetic rules: \(T^j T^k=T^{j+k}\) and \(\left(T^j\right)^k=T^{j k}\) for \(j, k \in \mathbb {N}\). Also, if \(V\) is a normed space and \(T \in \mathcal{B}(V)\), then

\[ \left\| T^{k}\right\| \leq \left\| T\right\| ^k \]

for each \(k \in \mathbb {N}\).

Recall that if \(z \in \mathbb {C}\) with \(|z|<1\), then the formula for the sum of a geometric series shows that

\[ \frac{1}{1-z}=\sum _{k=0}^{\infty } z^k \]

The following result demonstrates that this formula carries over to operators on Banach spaces.

Lemma 2 (Bounded operators on a Banach space lying in the open unit ball centered at \(I\) are invertible) Let \(V\) be a Banach space. Let \(T\) be a bounded operator on \(V\) (\(T \in \mathcal{B}(V)\)) with \(\left\| T\right\| < 1\). Then \(I-T\) is invertible and \[ (I-T)^{-1}=\sum _{k=0}^{\infty } T^k \]

The preceding result can be used to show that the set of invertible bounded operators on a Banach space is open.

Lemma 3 (Invertible bounded operators on a Banach space form an open set) Suppose \(V\) is a Banach space. Then \(\left\{ T \in \mathcal{B}(V) \; :\; T\text{ is invertible}\right\}\) is an open subset of \(\mathcal{B}(V)\).

Let \(V,W\) be normed spaces, let \(T\) be a bounded map: \(T \in \mathcal{B}(V,W)\).

  • \(T\) is called left-invertible if there exists \(S \in \mathcal{B}(W,V)\) such that \(ST = I\) (where \(I\) is the identity operator on \(V\)).

  • \(T\) is called right-invertible if there exists \(S \in \mathcal{B}(W,V)\) such that \(TS=I\) (where \(I\) is the identity operator on \(W\)).

One of the remarkable theorems of linear algebra states that left invertibility, right invertibility, and invertibility are all equivalent for operators (i.e., linear maps of \(V\) into itself) on a finite-dimensional normed space. The following example shows that this result fails on infinite-dimensional normed spaces.

ExampleExample 2

Give an example showing that left invertibility is not equivalent to right invertibility.

SolutionSolution

Define the right shift \(T: \ell^2 \rightarrow \ell^2\) and the left shift \(S: \ell^2 \rightarrow \ell^2\) as follows:

\[ T\left(a_1, a_2, a_3, \ldots \right)=\left(0, a_1, a_2, a_3, \ldots \right) \]

and

\[ S\left(a_1, a_2, a_3, \ldots \right)=\left(a_2, a_3, a_4, \ldots \right) . \]

It is easy to check that \(T,S\) are linear and bounded (do this yourself!).

Since \(ST=I\), we see that \(T\) is left-invertible, and \(S\) is right-invertible. However, the operator \(T\) is neither invertible nor right-invertible, since it is not surjective, and the operator \(S\) is neither invertible nor left-invertible, since it is not injective.

On finite-dimensional normed spaces, left invertibility is equivalent to injectivity. The following example shows that on infinite-dimensional normed spaces this also fails.

ExampleExample 3

Give an example of an injective but not left-invertible bounded map.

SolutionSolution

Define \(T: \ell^2 \rightarrow \ell^2\) as follows:

\[ T\left(a_1, a_2, a_3, \ldots \right)=\left(a_1, \frac{a_2}{2}, \frac{a_3}{3}, \ldots \right) . \]

Then \(T\) is an injective bounded operator on \(\ell^2\) (check!).

Let \(S\) be an operator on \(\ell^2\) such that \(S T=I\). For \(n \in \mathbb {N}\) let \(e_n \in \ell^2\) be the vector with 1 in the \(n^{\text{-th}}\) slot and 0 elsewhere. Then

\[ S e_n=S\left(n T e_n\right)=n(S T)\left(e_n\right)=n e_n . \]

The equation above implies that \(S\) is unbounded. Thus, \(T\) is not left-invertible, even though \(T\) is injective.

Lemma 4 (Equivalent conditions for left invertibility) Let \(V\) be a Banach space, \(T \in \mathcal{B}(V)\). The following conditions are equivalent:

  1. \(T\) is left-invertible;

  2. \(T\) is bounded below: \(\inf \limits_{\left\| f\right\| = 1}\left\| Tf\right\| > 0\).

  3. \(T\) is injective and has closed range (\(\operatorname {Im}T\) is a closed subspace);

  4. If \(V\) is a Hilbert space, an additional equivalent condition: \(T^*\) is a right-invertible operator.

  5. If \(V\) is a Hilbert space, an additional equivalent condition: \(T^*T\) is an invertible operator.

You may be familiar with the result that right invertibility is equivalent to surjectivity in finite-dimensional spaces. The following result shows that this equivalence also holds for infinite-dimensional Hilbert spaces.

Lemma 5 (Equivalent conditions for right invertibility) Let \(V\) be a Banach space, \(T \in \mathcal{B}(V)\). The following conditions are equivalent:

  1. \(T\) is right-invertible;

  2. \(T\) is surjective;

  3. If \(V\) is a Hilbert space, an additional equivalent condition: \(TT^{*}\) is an invertible operator.

Lemma 6 (Equivalent conditions for invertibility of an operator on a Banach space) Let \(V\) be a Banach space, \(T \in \mathcal{B}(V)\). The following conditions are equivalent:

  1. \(T\) is invertible, i.e., there exists a bounded operator \(T^{-1} \in \mathcal{B}(V)\) such that \(TT^{-1} = T^{-1}T = I\);

  2. \(T\) is bijective, i.e., surjective and injective;

  3. \(T\) is right-invertible and left-invertible;

  4. \(T\) is bounded below and \(\operatorname {Im}T\) is a dense (in \(V\)) set.

  5. If \(V\) is a Hilbert space, an additional equivalent condition: \(T^{*}\) is an invertible operator.

2 Spectrum

2.1 Definitions

Let \(V\) be a Banach space, \(T \in \mathcal{B}(V)\).

  • A scalar \(\lambda \in \mathbb {F}\) is called an eigenvalue if the equation \(Tf = \lambda f\) has some nonzero solution. Equivalently: \((T - \lambda I)f = 0\) has a nonzero solution. Equivalently: \(T - \lambda I\) is not injective. Notation for the set of all eigenvalues of an operator: \(\sigma_{p}(T)\).

  • The spectrum of the operator \(T\) consists of those scalars \(\lambda \in \mathbb {F}\) for which the operator \(T - \lambda I\) has no inverse. Notation: \(\sigma (T)\).

  • The resolvent of the operator \(T\) is the complement of the spectrum, i.e., all \(\lambda\) such that \(T - \lambda I\) is invertible. Notation: \(\rho (T)\). We have \(\rho (T) = \mathbb {C} \setminus \sigma (T)\).

    The operator \(R_{\lambda }(T) := (T - \lambda I)^{-1}\), \(\lambda \in \rho (T)\) is called the resolvent operator.

If the operator \(T-\lambda I\) is not injective, then it is not invertible. Thus, the set of eigenvalues of a bounded operator \(T\) is contained in the spectrum of \(T\): \(\sigma_{p}(T) \subseteq \sigma (T)\).

The Latin letter \(p\) in the notation for the set of all eigenvalues \(\sigma_p(T)\) comes from the English word point. Eigenvalues are also called the point spectrum.

If \(V\) is a finite-dimensional Banach space and \(T \in \mathcal{B}(V)\), then \(T-\lambda I\) is not injective if and only if \(T-\lambda I\) is not invertible. Thus, if \(T\) is an operator on a finite-dimensional Banach space, then the spectrum of \(T\) equals the set of eigenvalues of \(T\): \(\sigma_p(T) = \sigma (T)\).

However, on infinite-dimensional Banach spaces the spectrum of an operator need not equal the set of eigenvalues, as one can see in the following problems.

2.2 Basic properties

If \(\lambda \in \sigma_p(T)\) is an eigenvalue of an operator \(T \in \mathcal{B}(V)\), and \(f\) is an eigenvector of \(T\) corresponding to \(\lambda\), then

\[ \left\| T f\right\| =\left\| \lambda f\right\| =|\lambda |\left\| f\right\| , \]

which implies that \(|\lambda | \leq \left\| T\right\|\). The following result asserts that the same inequality holds for elements of \(\sigma (T)\).

Lemma 7 (\(T-\lambda I\) is invertible for large \(|\lambda |\)) Let \(T\) be a bounded operator on a Banach space. Then

  1. \(T - \lambda I\) is invertible for all \(\lambda\) with \(\left|\lambda \right| > \left\| T\right\|\). In other words, the spectrum of an operator lies in the (closed) ball around zero with radius equal to the norm of the operator:

\[ \sigma (T) \subseteq \overline{B}_{\left\| T\right\| }(0) = \left\{ \lambda \in \mathbb {F} \; : \; \left|\lambda \right| \leq \left\| T\right\| \right\} \]

  1. The norm of the resolvent operator \(R_{\lambda }(T) = T -\lambda I\) tends to zero as \(\lambda\) tends to \(\infty\):

\[ \left\| R_{\lambda }(T)\right\| \xrightarrow [\left|\lambda \right| \to \infty ]{} 0 \]

In general, the radius of the smallest closed ball around zero covering the spectrum is called the spectral radius of the operator \(T\):

\[ r_{\sigma }(T) := \sup _{\lambda \in \sigma (T)} \left|T\right| \]

As follows from the previous lemma, \(r_{\sigma }(T) \leq \left\| T\right\|\). However, the spectral radius can be found exactly without finding the spectrum itself.

Lemma 8 (Formula for the spectral radius) Let \(V\) be a Banach space, let \(T \in \mathcal{B}(V)\). Then \[ r_{\sigma }(T) = \lim _{n \to \infty } \sqrt[n]{\left\| T^n\right\| } \]

The set of eigenvalues of a bounded operator on a Banach space can be any bounded subset of \(\mathbb {F}\), even a non-measurable set! In contrast, the following result shows that the spectrum of a bounded operator is a closed subset of \(\mathbb {F}\). In this sense the spectrum is more convenient to work with than the point spectrum, i.e., the set of eigenvalues.

Lemma 9 (The spectrum is closed) The spectrum of a bounded operator on a Banach space is a closed subset of \(\mathbb {F}\).

Next, some useful formulas for the resolvent operator.

Lemma 10 Let \(V\) be a Banach space, let \(T \in \mathcal{B}(V)\). Let \(R_{\lambda } = R_{\lambda }(T) = (T - \lambda I)^{-1}\) be the resolvent operator for the bounded operator \(T\).

  1. The resolvent equation holds:

\[ R_{\lambda _1} - R_{\lambda _2} = (\lambda _1 - \lambda _2)R_{\lambda _1}R_{\lambda _2}, \qquad \lambda _1,\lambda _2 \in \rho (T) \]

  1. \(R_{\lambda }\) commutes with any bounded operator with which \(T\) commutes;

  2. Resolvent operators at different values of \(\lambda\) commute:

\[ R_{\lambda _1} R_{\lambda _2} = R_{\lambda _2} R_{\lambda _2}, \qquad \lambda _1,\lambda _2 \in \rho (T) \]

2.3 Classification of the spectrum

Let \(\lambda \in \sigma (T)\), i.e., \(T -\lambda I\) is not invertible. Three cases are possible:

  • \(T - \lambda I\) is not injective. In this case \(\lambda\) is an eigenvalue of \(T\). As already stated above, the set of all eigenvalues of \(T\) is called the point spectrum and is denoted \(\sigma_p(T)\).

  • \(T - \lambda I\) is injective. Nevertheless, \(T - \lambda I\) is still not invertible, i.e. (by Lemma 6) \(T - \lambda I\) must fail to be surjective: \(\operatorname {Im}(T - \lambda I) \neq V\). Let us examine \(\operatorname {Im}(T - \lambda I)\) more closely. There are 2 cases.

    • \(\operatorname {Im}(T - \lambda I)\) is a dense subset of \(V\). In other words, there is some element \(v\) in \(V\) such that \((T - \lambda I)(u)\) can be made as close to \(v\) as required, with \(u\) belonging to \(V\); but never equal to \(v\). By Lemma 6 this is equivalent to \(T - \lambda I\) not being bounded below (i.e., it brings elements of \(V\) that are at a substantial distance from each other close together). Equivalently, the inverse linear operator \((T - \lambda I)^{-1}\), which one might try to define on the dense set \(\operatorname {Im}(T - \lambda I)\), is not a bounded operator and, hence, cannot be extended to all of \(V\). In this case one says that \(\lambda\) lies in the continuous spectrum \(\sigma_c(T)\) of the operator \(T\).

    • \(\operatorname {Im}(T - \lambda I)\) is not dense in \(V\). Such \(\lambda\) are called points of the residual spectrum. Notation: \(\sigma_{r}(T)\).

Altogether, the spectrum splits into the point, continuous, and residual spectra:

\[ \sigma (T) = \sigma _{p}(T) \sqcup \sigma _c(T) \sqcup \sigma _r(T) \]

2.4 Spectrum vs. polynomials

Let \(T\) be an operator on a vector space \(V\), and let \(p\) be a polynomial with coefficients in \(\mathbb {F}\):

\[ p(z)=b_0+b_1 z+\cdots +b_n z^n . \]

Then \(p(T)\) is the operator on \(V\) defined as:

\[ p(T)=b_0 I+b_1 T+\cdots +b_n T^n . \]

Check that if \(p\) and \(q\) are polynomials with coefficients in \(\mathbb {F}\) and \(T\) is an operator, then:

\[ (p q)(T)=p(T) q(T) \]

The following result provides a convenient way to compute the spectrum of a polynomial applied to an operator. For example, this result implies that if \(T\) is a bounded operator on a complex Banach space, then the spectrum of \(T^2\) consists of the squares of all numbers in the spectrum of \(T\).

As with the previous result, the following result does not apply to real Banach spaces. The proof uses the factorization of a polynomial with complex coefficients as a product of polynomials of degree \(1\), which need not be possible when restricted to the field of real numbers.

Theorem 1 (Spectral mapping theorem) Let \(T\) be a bounded operator on a complex Banach space, and let \(p\) be a polynomial with complex coefficients. Then \[ \sigma (p(T))=p(\sigma (T)) . \]

3 Compact operators

Recall that in infinite-dimensional Banach spaces closed balls are not compact, despite being bounded and closed. A compact operator is an operator that maps closed balls to relatively compact sets (i.e., sets whose closure is compact). Compact operators, in their behavior, come as close as possible to the behavior of matrices or operators on a finite-dimensional normed space (which, as we proved last semester, is necessarily Banach). We will work out the nuances of the definition a bit later, but for now let us recall the convenient spectral properties of matrices and finite-dimensional operators.

3.1 Spectral properties: the Fredholm alternative

3.1.1 The spectrum of a matrix

Let us recall results from the theory of matrices. First, the set of eigenvalues of a matrix coincides with those scalars \(\lambda\) for which \(A- \lambda E\) is degenerate (not invertible). In other words, the spectrum and the set of eigenvalues are one and the same.

Next, the Jordan decomposition. An arbitrary matrix of order \(n\) over the field \(\mathbb {C}\) can be brought, by a change of basis, to an “almost” diagonal form, or more precisely to a block-diagonal form in which Jordan blocks lie on the diagonal. A Jordan block is a square submatrix whose main diagonal is filled with identical numbers, the next diagonal is filled with ones, and all other entries are zero. Such a form of the matrix is called the Jordan normal form (JNF). Example:

\[ A =\operatorname {diag}\bigg(J_{2}(-2i), J_3(-2i),J_1(3),J_1(3),J_4(3),J_1(-7)\bigg) = \begin{pmatrix} -2i & 1 & & & & & & & & & & \\ 0 & -2i & & & & & & 0 & & & & \\ & & -2i & 1 & 0 & & & & & & & \\ & & 0 & -2i & 1 & & & & & & & \\ & & 0 & 0 & -2i & & & & & & & \\ & & & & & 3 & & & & & & \\ & 0 & & & & & 3 & & & & & \\ & & & & & & & 3 & 1 & 0 & 0 & \\ & & & & & & & 0 & 3 & 1 & 0 & \\ & & & & & & & 0 & 0 & 3 & 1 & \\ & & & & & & & 0 & 0 & 0 & 3 & \\ & & & & & & & & & & & -7 \\ \end{pmatrix} \]

The advantage of the Jordan decomposition is that it can be obtained for any matrix, unlike diagonalization. Moreover, a great deal of information about the matrix can be extracted from the JNF. For instance, the JNF is upper triangular, so the eigenvalues of the matrix are the numbers on the diagonal, and their number equals the algebraic multiplicity. For the matrix \(A\) above, the eigenvalues are: \(-2i, 3, -7\). The algebraic multiplicities:

\[ \operatorname {AlgMult}_{A}(-2i) = 5, \quad \operatorname {AlgMult}_{A}(3) = 6, \quad \operatorname {AlgMult}_{A}(-7) = 1 \]

Notice moreover (check for yourself!) that if for an eigenvalue \(\lambda\) we start raising the matrix \((A - \lambda E)\) to increasing powers, then at some point the kernel stabilizes (recall that it cannot decrease). In other words, there is a natural number \(m \leq n\) such that

\[ \begin{align} \operatorname {Ker}(A - \lambda E)^{m-1} \subsetneq \operatorname {Ker}(A - \lambda E)^{m} & = \operatorname {Ker}(A - \lambda E)^{m+1} = \operatorname {Ker}(A - \lambda E)^{m+2} = \ldots = \\ & = \operatorname {Ker}(A - \lambda E)^{n} = \operatorname {Ker}(A - \lambda E)^{n+1} = \ldots \end{align} \]

(think about why stabilization occurs by \(n\)). This number is called the index of the eigenvalue \(\lambda\), denoted \(\operatorname {ind}_{A}(\lambda )\), and it equals the maximal size of a Jordan block for \(\lambda\) (check!). In our particular example:

\[ \operatorname {ind}_{A}(-2i) = 3, \quad \operatorname {ind}_{A}(3) = 4, \quad \operatorname {ind}_{A}(-7) = 1 \]

\(\operatorname {Ker}(A - \lambda E)^n\) is called the generalized eigenspace. One can notice (check for yourself!) that the algebraic multiplicity turns out to equal precisely the dimension of the generalized eigenspace:

\[ \operatorname {AlgMult}_{A}(\lambda )= \operatorname {dim}\operatorname {Ker}(A - \lambda E)^{\operatorname {Ind}_A(\lambda )} = \operatorname {dim}\operatorname {Ker}(A - \lambda E)^n \]

This formula is rarely given in a linear algebra course, though in our view it is very useful, since it allows one to define the algebraic multiplicity abstractly (i.e., without passing to a basis, without forming the characteristic polynomial) for a finite-dimensional operator, similarly to the geometric multiplicity.

Next, the geometric multiplicity, i.e., the dimension of the eigenspace \(\operatorname {Ker}(A - \lambda E)\), equals the number of Jordan blocks (check!):

\[ \operatorname {GeomMult}_A(-2i) = 2, \quad \operatorname {GeomMult}_{A}(3) = 3, \quad \operatorname {GeomMult}_{A}(-7) = 1 \]

Next, the whole space \(\mathbb {C}^{n}\) decomposes into a direct sum of generalized eigenspaces:

\[ \mathbb {C}^{n} = \bigoplus _{\lambda \in \sigma (A)} \operatorname {Ker}(A - \lambda E)^n \]

Let us state abstractly (i.e., without passing to a basis, without forming matrices) the facts suggested by the preceding discussion 1.

Theorem 2 Let \(V\) be a finite-dimensional normed space (over \(\mathbb {R}\) or over \(\mathbb {C}\)), let \(T \in \mathcal{B}(V) = \mathcal{L}(\nu )\) (any linear map \(V \mapsto V\) is bounded, since \(V\) is finite-dimensional). Then

  • \(\sigma_{p}(T) = \sigma (T)\) (the spectrum consists entirely of eigenvalues);

  • Every \(\lambda \in \mathbb {F}\) has a finite index and finite algebraic multiplicity: there is a number \(m = \operatorname {Ind}_{T}(\lambda ) \in \mathbb {N}\) such that

    \[ \operatorname {Ker}(T - \lambda I)^{m-1} \subsetneq \operatorname {Ker}(T - \lambda I)^{m} = \operatorname {Ker}(T - \lambda I)^{m+1} = \operatorname {Ker}(T - \lambda I)^{m+2} = \ldots \]

    The subspace \(\operatorname {Ker}(T - \lambda I)^m\) is, accordingly, called the generalized eigenspace for \(\lambda\). Its dimension is finite:

    \[ \operatorname {AlgMult}_{T}(\lambda ) = \operatorname {dim}\operatorname {Ker}(T - \lambda I)^{\operatorname {Ind}_{T}(\lambda )} < \infty \]

3.1.2 The spectrum of a compact operator

As we saw in the section on operators on Banach spaces, in infinite-dimensional spaces the spectrum behaves well (for instance, it is always compact in \(\mathbb {F}\), i.e., closed and bounded), unlike the eigenvalues. On the other hand, eigenvalues are easier to find: it is easier to solve the equation \(Tf= \lambda f\) than to determine when \(T - \lambda I\) is not invertible. Compact operators are precisely those operators for which the spectrum almost coincides with the eigenvalues.

Theorem 3 Let \(V\) be a Banach space, let \(T\) be a compact operator. Then

  • Let \(\lambda \neq 0\). Then \(\lambda \in \sigma (T) \iff \lambda \in \sigma_p(T)\). In other words, the spectrum of a compact operator almost coincides with the eigenvalues; they can differ only at zero.

  • For zero:

    • if \(\operatorname {dim}V < \infty\), then \(0 \in \sigma (T)\) \(\iff\) \(0 \in \sigma_p(T)\);

    • if \(\operatorname {dim}V = \infty\), then always \(0 \in \sigma (T)\) (i.e., a compact operator is always non-invertible on infinite-dimensional Banach spaces), however \(0\) need not lie in \(\sigma_p(T)\), i.e., need not be an eigenvalue.

  • A limit point of \(\sigma_p(T)\) and of \(\sigma (T)\) can occur only at zero;

  • \(\sigma (T)\) and \(\sigma_p(T)\) are at most countable.

  • Every nonzero element of the spectrum (i.e., eigenvalue) \(\lambda\) has finite index and finite algebraic multiplicity: there is a number \(m = \operatorname {Ind}_{T}(\lambda ) \in \mathbb {N}\) such that

    \[ \operatorname {Ker}(T - \lambda I)^{m-1} \subsetneq \operatorname {Ker}(T - \lambda I)^{m} = \operatorname {Ker}(T - \lambda I)^{m+1} = \operatorname {Ker}(T - \lambda I)^{m+2} = \ldots \]

    The subspace \(\operatorname {Ker}(T - \lambda I)^m\) is, accordingly, called the generalized eigenspace for \(\lambda\). Its dimension is finite:

    \[ \operatorname {AlgMult}_{T}(\lambda ) = \operatorname {dim}\operatorname {Ker}(T - \lambda I)^{\operatorname {Ind}_{T}(\lambda )} < \infty \]

Altogether, if \(V\) is an infinite-dimensional Banach space, then outside of zero \(\sigma_p(T)\) coincides with \(\sigma (T)\), and this set is either finite or a sequence converging to zero. Zero itself must necessarily lie in \(\sigma (T)\). Whether zero lies in \(\sigma_p(T)\) must be determined separately.

The fact that the spectrum coincides with the eigenvalues is so important that it has its own name.

Theorem 4 (The Fredholm alternative) Let \(V\) be a Banach space, \(T\) a compact operator, \(\lambda \in \mathbb {F} \setminus \left\{ 0\right\}\). Then the following conditions are equivalent:

  1. \(T - \lambda I\) is not invertible (i.e., \(\lambda \in \sigma (T)\));

  2. \(T - \lambda I\) is not injective (i.e., \(\lambda \in \sigma_p(T)\));

  3. \(T - \lambda I\) is not surjective.

The name of this result traditionally contains the word “alternative,” since it can be rephrased as follows: if \(T\) is a compact operator on a Banach space \(V\) and \(\lambda \in \mathbb {F}\setminus \left\{ 0\right\}\), then exactly one of the following conditions holds:

  • either the equation \(Tf = \lambda f\) has a nonzero solution \(f \in V\);

  • or the equation \(g = Tf - \lambda f\) has a solution \(f \in V\) for every possible \(g \in V\).

3.2 Definition of a compact operator

Let \(V,W\) be normed spaces, and let \(T: V \to W\) be a linear map. The following statements are equivalent, and different authors may choose any one of them as the primary definition of the map \(T\) being compact:

  1. there exists a neighborhood \(U\) of zero in \(V\) such that \(T(U)\) is a relatively compact subset of \(W\) (i.e., the closure of \(T(U)\) is compact);

  2. there exists a neighborhood \(U\) of zero in \(V\) and a compact subset \(V \subseteq W\) such that \(T(U) \subseteq V\);

  3. there exists a nonempty open set \(U\) in \(V\) such that \(T(U)\) is a relatively compact subset of \(W\).

  4. the image of the unit ball of \(V\) under the operator \(T\) is relatively compact in \(W\);

  5. the image of any bounded subset of \(V\) under the operator \(T\) is relatively compact in \(W\);

  6. for any bounded sequence \((x_n)_{n\in \mathbb {N}}\) in \(V\), the sequence \((Tx_n)_{n\in \mathbb {N}}\) contains a convergent subsequence.

  7. if additionally \(W\) is a Banach space, then these statements are also equivalent to the following: the image of any bounded subset of \(V\) under the operator \(T\) is totally bounded in \(W\).

Denote by \(\mathcal{K}(V,W)\) the set of all compact linear maps. \(\mathcal{K}(V) := \mathcal{K}(V,V)\).

3.3 Basic properties

Theorem 5 Let \(V\) and \(W\) be Banach spaces. Then

  1. any compact map is bounded: \(\mathcal{K}(V, W) \subset \mathcal{B}(V, W)\);

  2. \(\mathcal{K}(V, W)\) is a closed subspace of \(\mathcal{B}(V, W)\). That is, if \((T_{n})\) is a sequence of compact maps and \(T \in \mathcal{B}(V, W)\) are such that \(\left\| T_n - T\right\| \rightarrow 0\), then \(T \in \mathcal{K}(V, W)\).

A linear map \(T: V \rightarrow W\) is said to have finite rank if \(\operatorname {Im}T\) is a finite-dimensional subspace of \(W\).

Theorem 6 Let \(V\) and \(W\) be Banach spaces. Any linear map of finite rank from \(V\) to \(W\) is compact.

Let \(g \in C[0,1]\). Define the integral transform operator: \(T_g: C[0,1] \to C[0,1]\), \[ (T_gf)(x) := \int _0^x f(t) g(t) \; dt \] Show that it is compact.

SolutionSolution

Let \((f_n)\) be a bounded sequence: \(\left\| f_n\right\| = \sup_{x \in [0,1]}\left|f(x)\right| \leq C\) for some constant \(C > 0\). What can be said about the sequence \((T_gf_n)\)?

  • Is \((T_gf_n)\) uniformly bounded?

    \[ \left\| T_gf_n\right\| \leq \int _0^x \left|f(t)g(t)\right| dt \leq C \cdot \left\| g\right\| \]

    Yes.

  • Is \((T_gf_n)\) equicontinuous?

    \[ \left|(T_gf_n)(x_1) - (T_gf_n)(x_2)\right| = \left|\int _{x_1}^{x_2} f_n(t)g(t) dt\right| \leq \int _{x_1}^{x_2} \left|f_n(t)g(t)\right| dt \leq \int _{x_1}^{x_2} C \cdot \left\| g\right\| dt = C \cdot \left\| g\right\| \cdot \left|x_1 - x_2\right| \]

    Yes.

By the Arzela-Ascoli theorem the sequence \((T_gf_n)_{n \in \mathbb {N}}\) is relatively compact, so a convergent subsequence can be extracted from it.

SolutionSolution

Suppose that \(T\) is surjective. Then by the open mapping theorem \(T\) is an open map (maps open sets to open sets). Enum-item(ii)

4 The adjoint map

Definition 1 Let \(V\) and \(W\) be Hilbert spaces, and \(T: V \rightarrow W\) a bounded linear map. The adjoint of \(T\) is the map \(T^{*}: W \rightarrow V\) such that \[ \left\langle T f, g \right\rangle _{W}= \left\langle f, T^{*} g \right\rangle _{V} \] for all \(f \in V\) and all \(g \in W\).

To see why this definition makes sense, fix \(g \in W\). Consider the linear functional on \(V\) given by the formula \(f \mapsto \left\langle T f, g \right\rangle\). This linear functional is bounded, since

\[ | \left\langle T f, g \right\rangle | \leq \left\| T f\right\| \left\| g\right\| \leq \left\| T\right\| \left\| g\right\| \left\| f\right\| \]

for all \(f \in V\); hence, the functional \(f \mapsto \left\langle T f, g \right\rangle\) has norm at most \(\left\| T\right\| \left\| g\right\|\). By the Riesz representation theorem there is a unique element of the space \(V\) (with norm at most \(\left\| T\right\| \left\| g\right\|\)) such that this functional is given by the inner product with this element. Denote this unique element by \(T^{*} g\). In other words, \(T^{*} g\) is the unique element of the space \(V\) for which

\[ \left\langle T f, g \right\rangle _W = \left\langle f, T^{*} g \right\rangle _V \]

for all \(f \in V\). Moreover,

\[ \left\| T^{*} g\right\| \leq \left\| T\right\| \left\| g\right\| . \]

SolutionSolution
Enum-item(1)

Linearity is obvious. \(\left\| M_{h}\right\| \leq \left\| h\right\|_{\infty }\).

Enum-item(2)

\[ \left\langle M_{h} f, g \right\rangle =\int f h \overline{g} d \mu = \left\langle f, M_{\overline{h}} g \right\rangle \]

for all \(f, g \in L^{2}(\mu )\), we get \(M_{h}^{*}=M_{\overline{h}}\).

ExampleExample 8

Let \((X, \mathcal{F}_{X}, \mu )\) and \((Y, \mathcal{F}_{Y}, \nu )\) be two spaces with \(\sigma\)-finite measures. Let \(K \in \mathcal{L}^2(\mu \times \nu )\). Denote \[ V = L^2(X, \mathcal{F}_{X}, \mu ) = L^2(\mu ), \qquad W = L^2(Y, \mathcal{F}_{Y}, \nu ) = L^2(\nu ) \] Define the map \(T_{K}: W \to V\) as follows: \[ (T_{K}f)(x) = \int _{Y}K(x,y)f(y) \; d\nu (y), \qquad f \in W = L^2(\nu ) \] This operator is called the Hilbert-Schmidt integral transform. The function \(K\) is called the kernel of the transform.

  1. Prove that \(T_{K}\) is well defined. Namely, show that if \(f \in L^2(\mu )\), then \(T_{K}f \in L^2(\nu )\), i.e., \(T_Kf\) is measurable and \(\int_{X}\left|T_Kf\right|^2 \; d\mu < \infty\);

  2. Prove that \(T_{K}\) is a bounded linear map, i.e., \(T_{K} \in \mathcal{B}(V,W)\).

  3. Characterize \(T^*_K\).

SolutionSolution
Enum-item(1)

To see that the definition makes sense, first note that there is no issue with measurability, since for each \(x \in X\) the function \(y \mapsto K(x, y)\) is a \(T\)-measurable function on \(Y\) (one of the properties of measurable functions on a product of spaces).

Next, suppose \(f \in L^{2}(\nu )\). Using the Cauchy-Bunyakovsky-Schwarz inequality, for each fixed \(x \in X\) we get

\[ \begin{align} \left|(T_K f)(x)\right|^2 & \leq \left(\int _{Y} \left|K(x,y)\right| \cdot \left|f(y)\right| \; dv(y)\right)^2 = \left( \left\langle \left|K(x, \cdot )\right|, f(\cdot ) \right\rangle _{L^2(\nu )}\right)^2 \leq \\ & = \left\| K(x, \cdot )\right\| ^2_{L^2(\nu )} \cdot \left\| f\right\| ^2_{L^2(\nu )} = \\ & = \int _{Y} \left|K(x,y)\right|^2 \; d\nu (y) \cdot \left\| f\right\| ^2_{L^2(\nu )} \end{align} \]

Now let us integrate over \(x\), and we get

\[ \underbrace{\int _{X}\left|(T_K f)(x)\right|^2 d \mu (x)}_{\left\| T_Kf\right\| ^2_{L(\mu )}} \leq \left(\int _{X} \int _{Y} \left|K(x,y)\right|^2 \; d\nu (y) \; d\mu (x) \right) \cdot \left\| f\right\| ^2_{L^2(\nu )} \]

By Tonelli’s theorem the iterated integral \(\int_X\int_Y\) can be replaced by the double integral \(\int_{X \times Y}\). As a result we obtain

\[ \left\| T_Kf\right\| ^2_{L(\mu )} \leq \left(\int _{X \times Y} \left|K\right|^2 \; d\mu \times \nu \right) \cdot \left\| f\right\| ^2_{L^2(\nu )} = \left\| K\right\| ^2_{L^2(\mu \times \nu )} \cdot \left\| f\right\| ^2_{L^2(\nu )} \]

The inequality above implies that the integral on the left-hand side is finite for \(\mu\)-almost all \(x \in X\). Thus, the integral in the definition makes sense for \(\mu\)-almost all \(x \in X\).

Enum-item(2)

From the previous item:

\[ \left\| T_Kf\right\| _{L(\mu )} \leq \left\| K\right\| _{L^2(\mu \times \nu )} \cdot \left\| f\right\| _{L^2(\nu )} \]

Thus, \(T_{K}\) is a bounded linear map from \(L^{2}(\nu )\) to \(L^{2}(\mu )\) and

\[ \left\| T_K\right\| \leq \left\| K\right\| _{L^2(\mu \times \nu )} \]

Enum-item(3)

Define \(K^{*}: Y \times X \rightarrow \mathbb {F}\) as follows:

\[ K^{*}(y, x)=\overline{K(x, y)}, \]

and note that \(K^{*} \in \mathcal{L}^{2}(v \times \mu )\). Thus, \(T_{K^{*}}: L^{2}(\mu ) \rightarrow L^{2}(\nu )\) is a bounded linear map. Using Tonelli’s theorem and Fubini’s theorem, we obtain:

\[ \begin{align} \left\langle T_{K} f, g \right\rangle _{L^2(\mu )} & = \int _{X} \left(T_{K}f\right)(x) \cdot \overline{g(x)} \; d\mu (x) = \\ & = \int _{X} \left( \int _{Y} K(x, y) f(y) d\nu (y)\right) \cdot \overline{g(x)} \; d \mu (x) \\ & =\int _{Y} f(y) \left(\int _{X} K(x, y) \overline{g(x)} d \mu (x)\right) d\nu (y) \\ & =\int _{Y} f(y) \cdot \overline{\left(T_{K^{*}} g\right)(y)} d\nu (y)= \left\langle f, T_{K^{*}} g \right\rangle _{L^2(\nu )} \end{align} \]

for all \(f \in L^{2}(\nu )\) and all \(g \in L^{2}(\mu )\). Thus,

\[ \left(T_K\right)^* = T_{K^*} \]

ExampleExample 9

Let \(m,n \in \mathbb {N}\), let \(V = \mathbb {F}^m\), \(W = \mathbb {F}^n\), let \(K \in \mathbb {F}^{m \times n}\). Show that the map \[ w \mapsto K \cdot w, \qquad W \to V \] given by multiplication by the matrix \(K\) is a special case of the Hilbert-Schmidt integral operator. Find the adjoint.

SolutionSolution

  • Let \(\mu\) be counting measure on \(\left\{ 1, \ldots , m\right\}\), \(\nu\) counting measure on \(\left\{ 1, \ldots , n\right\}\). Then the space

    \[ L^2\left(\left\{ 1,\ldots ,m\right\} , 2^{\left\{ 1,\ldots ,m\right\} }, \mu \right) \]

    consists of all possible functions \(f \in \left\{ 1,\ldots ,m\right\} \to \mathbb {F}\) that are square-summable: \(\sum_{k=1}^m\left|f(k)\right|^2 < \infty\). This last restriction plays no role, since there are finitely many terms, and hence the sum always converges. In other words, the space \(L^2\left(\left\{ 1,\ldots ,m\right\} , 2^{\left\{ 1,\ldots ,m\right\} }, \mu \right)\) consists of all possible functions from \(\left\{ 1,\ldots ,m\right\}\) to \(\mathbb {F}\). They can be identified with vectors from \(\mathbb {F}^m\) with the standard inner product between them:

    \[ L^2\left(\left\{ 1,\ldots ,m\right\} , 2^{\left\{ 1,\ldots ,m\right\} }, \mu \right) \; \cong \; \mathbb {F}^m \]

    For more detail see the example about \(\ell^p\) and \(\mathbb {F}^n\) as Lebesgue spaces

    Similarly, the matrix \(K\) can be identified with a square-summable function from \(\left\{ 1,\ldots ,m\right\} \times \left\{ 1,\ldots ,n\right\}\) to \(\mathbb {F}\). In this case the Hilbert-Schmidt integral transform \(T_K: L^{2}(\nu ) \rightarrow L^{2}(\mu )\), induced by integration with kernel \(K\), is given as follows:

    \[ \left(T_K w\right)(i) = \int _{\left\{ 1,\ldots ,n\right\} } K(i,j) \cdot w(j) \cdot d\nu (j) = \sum _{j = 1}^{n}K(i,j) \cdot w(j) = (K \cdot w)_{i} \]

    The computation above shows that the linear map \(T_K\) is simply multiplication by the matrix \(K\).

    In this case \(K^{*}\) is the conjugate transpose matrix of \(K\), since the \(n\)×m matrix \(K^{*}\) is obtained by swapping the rows and columns of \(K\) and then taking the complex conjugate of each entry.

  • Let us find the adjoint. Recall that \((T_K)^* = T_{K^*}\), where \(K^*(j,i) = \overline{K(i,j)}\). That is, \(K^* = \overline{K^T}\) is the Hermitian adjoint matrix of \(K\). In other words, the adjoint of multiplication by a matrix is multiplication by the Hermitian adjoint matrix. This result may be familiar to you from linear algebra.

    In the case \(\mathbb {F} = \mathbb {R}\) conjugation is unnecessary and \(K^*\) is simply the transpose of \(K\).

Lemma 11 (Properties of the adjoint) Suppose \(V, W\) and \(U\) are Hilbert spaces. Then:

  1. If \(T \in \mathcal{B}(V,W)\), then \(T^* \in \mathcal{B}(W,V)\), moreover \(\left(T^*\right)^* = T\) and \(\left\| T\right\| = \left\| T^*\right\|\);

  2. If \(T \in \mathcal{B}(V,W)\), then \(\left\| T^*T\right\| = \left\| T\right\|^2\);

  3. \((S+T)^{*}=S^{*}+T^{*}\) for all \(S, T \in \mathcal{B}(V, W)\);

  4. \((\alpha T)^{*}=\overline{\alpha } \cdot T^{*}\) for all \(\alpha \in \mathbb {F}\) and all \(T \in \mathcal{B}(V, W)\);

  5. \(I^{*}=I\), where \(I\) is the identity operator on \(V\);

  6. \((ST)^{*}=T^{*}S^{*}\) for all \(T \in \mathcal{B}(V, W)\) and \(S \in \mathcal{B}(W, U)\).

Lemma 12 (Relation between the range and kernel of an operator and its adjoint) Suppose \(V\) and \(W\) are Hilbert spaces, and \(T \in \mathcal{B} (V, W)\). Then

  1. \(\operatorname {Ker} T= \left(\operatorname {Im}T^*\right)^{\perp }\);

  2. \(\overline{\operatorname {Im} T} = \left(\operatorname {Ker}T^*\right)^{\perp }\).

Lemma 13 (Necessary and sufficient condition for a dense range) Suppose \(V\) and \(W\) are Hilbert spaces and \(T \in \mathcal{B}(V, W)\). Then \(T\) has dense range if and only if \(T^{*}\) is injective.

\[ K(x, y)= \begin{cases} 1 & \text{ if } x>y, \\ 0 & \text{ if } x \leq y .\end{cases} \]

In other words, \(K\) is the characteristic function of the open triangle below the diagonal of the unit square. Clearly \(K \in \mathcal{L}^{2}(\lambda \times \lambda )\) and \(\mathcal{V}=T_K\), the Hilbert-Schmidt integral operator. for \(f \in L^{2}([0,1])\) and \(x \in [0,1]\).

5.1 Self-adjoint operators

A bounded operator \(T\) on a Hilbert space is called self-adjoint if \(T^{*}=T\). \(T \in \mathcal{B}(V)\) is self-adjoint if and only if

\[ \left\langle T f, g \right\rangle = \left\langle f, T g \right\rangle \]

for all \(f, g \in V\).

Some insight into the adjoint operator can be gained by regarding the operation \(T \mapsto T^{*}\) on \(\mathcal{B}(V)\) as an analogue of the operation \(z \mapsto \overline{z}\) on \(\mathbb {C}\). Under this analogy, self-adjoint operators (characterized by \(T^{*}=T\)) correspond to real numbers (characterized by \(\overline{z}=z\)).

The following two results deepen the analogy between self-adjoint operators and real numbers. First we see this analogy reflected in the behavior of \(\left\langle T f, f \right\rangle\), and then in the spectrum of \(T\).

Lemma 15 Suppose \(T\) is a bounded operator on a complex Hilbert space \(V\). Then \(T\) is self-adjoint if and only if \[ \left\langle T f, f \right\rangle \in \mathbb {R} \] for all \(f \in V\).

Lemma 16 (Self-adjoint operators have real spectrum) Let \(T\) be a bounded self-adjoint operator on a Hilbert space. Then \(\sigma (T) \subseteq \mathbb {R}\).

This lemma is vacuous in the case \(\mathbb {F} = \mathbb {R}\) (in this case the spectrum cannot fall outside the eigenvalues anyway), but in the case \(\mathbb {F} = \mathbb {C}\) it acquires content.

We have shown that a bounded operator on a nonzero complex Hilbert space has nonempty spectrum. This result can fail on real Hilbert spaces (where by definition the spectrum is contained in \(\mathbb {R}\)). For example, the operator \(T\) on \(\mathbb {R}^{2}\) defined by \(T(x, y)=(-y, x)\) has empty spectrum.

Although the spectrum of every self-adjoint operator is nonempty, it is not true that every self-adjoint operator has an eigenvalue. For example, the self-adjoint operator \(M_{x} \in \mathcal{B}\left(L^{2}[0,1]\right)\), defined by \(\left(M_{x} f\right)(x)=x f(x)\), has no eigenvalues.

5.2 Normal operators

Now let us consider another good special class of operators. A bounded operator \(T\) on a Hilbert space is called normal if it commutes with its adjoint:

\[ T^{*} T=T T^{*} . \]

Clearly every self-adjoint operator is normal, but there exist normal operators that are not self-adjoint, as shown in the following example.

ExampleExample 12
SolutionSolution

Lemma 17 (Criterion for a normal operator) Let \(T\) be a bounded operator on a Hilbert space \(V\). Then \(T\) is normal if and only if \[ \left\| T f\right\| =\left\| T^{*} f\right\| \] for all \(f \in V\).

Every complex number \(z\) can be written as \(a+b i\), where \(a\) and \(b\) are real numbers, with \(a = \frac{z + \overline{z}}{2}\) and \(b = \frac{z - \overline{z}}{2i}\). Let us try to apply the same idea to a bounded operator \(T\) on a Hilbert space \(V\): let

\[ \operatorname {Re}T := A = \frac{T + T^*}{2}, \qquad \operatorname {Im}T := B = \frac{T - T^*}{2i} \]

The first part of the following result gives an analogous result for bounded operators on a complex Hilbert space, where self-adjoint operators play the role of real numbers. The operators \(A\) and \(B\) can be called the real and imaginary parts of the operator \(T\). The second part below shows that normality depends on whether these real and imaginary parts commute.

Lemma 18 (An operator is normal if and only if its real and imaginary parts commute) Let \(T\) be a bounded operator on a complex Hilbert space \(V\).

  1. There exist unique self-adjoint operators \(A, B\) on \(V\) such that \(T=A+i B\).

  2. \(T\) is normal if and only if \(A B=B A\), where \(A, B\) are as in part (a).

SolutionSolution

Proof. Suppose \(T=A+i B\), where \(A\) and \(B\) are self-adjoint. Then \(T^{*}=A-i B\). Adding these equations for \(T\) and \(T^{*}\) and then dividing by 2, we get the formula for \(A\); subtracting the equation for \(T^{*}\) from the equation for \(T\) and then dividing by \(2 i\), we get the formula for \(B\). In particular, we have:

\[ A=\frac{T+T^{*}}{2} \quad \text{ and } \quad B=\frac{T-T^{*}}{2 i}, \]

which proves the uniqueness in part (a). Existence in part (a) is proved by defining \(A\) and \(B\) via the equations above and observing that \(A\) and \(B\), as defined above, are self-adjoint and \(T=A+i B\).

To prove (b), let us check that if \(A\) and \(B\) are defined as in the equations above, then

\[ A B-B A=\frac{T^{*} T-T T^{*}}{2 i} . \]

Thus, \(A B=B A\) if and only if \(T\) is normal.

An operator on a finite-dimensional vector space is left-invertible if and only if it is right-invertible. We have seen that this result fails for bounded operators on infinite-dimensional Hilbert spaces. However, the following result shows that we recover this equivalence for normal operators.

Lemma 19 (Invertibility for normal operators) Suppose \(V\) is a Hilbert space, and \(T \in \mathcal{B}(V)\) is a normal operator. Then the following statements are equivalent:

  1. \(T\) is invertible.

  2. \(T\) is left-invertible.

  3. \(T\) is right-invertible.

  4. \(T\) is surjective.

  5. \(T\) is injective and bounded below;

  6. \(T\) is injective and has closed range.

  7. \(T^{*} T\) is invertible.

  8. \(T T^{*}\) is invertible.

The following result shows that a normal operator and its adjoint have the same eigenvectors, with their eigenvalues being complex conjugates of each other. This result can fail for operators that are not normal. For example, 0 is an eigenvalue of the left shift on \(\ell^{2}\), but its adjoint, the right shift, has no eigenvectors or eigenvalues.

Lemma 20 (For a normal operator, \(\sigma_p(T^*) = \overline{\sigma_p(T)}\)) Let \(T\) be a normal operator on a Hilbert space \(V, \alpha \in \mathbb {F}\), and \(f \in V\). Then \(\alpha\) is an eigenvalue of \(T\) with eigenvector \(f\) if and only if \(\overline{\alpha }\) is an eigenvalue of \(T^{*}\) with eigenvector \(f\).

Since every self-adjoint operator is normal, the following result also holds for self-adjoint operators.

Lemma 21 (Eigenvectors of normal operators are orthogonal) Eigenvectors of a normal operator corresponding to distinct eigenvalues are orthogonal.

5.3 Isometries and unitary operators

Let \(T\) be a bounded operator on a Hilbert space \(V\).

  • \(T\) is called an isometry if \(\left\| T f\right\| =\left\| f\right\|\) for every \(f \in V\).

  • \(T\) is called unitary if \(T^{*} T=T T^{*}=I\). In other words, \(T^{-1} = T^*\).

  1. \(T\) is an isometry.

  2. \(T\) preserves the inner product: \(\left\langle Tf, Tg \right\rangle = \left\langle f, g \right\rangle\) for any \(f,g \in V\).

  4. \(T\) maps any orthonormal family of vectors to another orthonormal family;

  5. \(T\) maps some orthonormal family of vectors to another orthonormal family.

  1. \(T\) is a unitary operator.

  2. \(T\) is a surjective isometry.

  3. \(T\) and \(T^{*}\) are isometries.

  4. \(T^{*}\) is a unitary operator.

  5. \(T\) is an invertible operator, and \(T^{-1}=T^{*}\).

  6. \(T\) maps any orthonormal basis to another orthonormal basis;

  7. \(T\) maps some orthonormal basis to another orthonormal basis.

The equations \(T^{*} T=T T^{*}=I\) are analogous to the equation \(|z|^{2}=1\) for \(z \in \mathbb {C}\). Let us now extend this analogy to the behavior of the spectrum of a unitary operator.

Lemma 24 (Spectrum of a unitary operator) Let \(T\) be a unitary operator on a Hilbert space. Then \[ \sigma (T) \subseteq \left\{ \alpha \in \mathbb {F}:|\alpha |=1\right\} . \]

As a special case of the following result we can conclude (without any computation!) that the spectrum of the right shift on \(\ell^{2}\) equals \(\left\{ \alpha \in \mathbb {F}:|\alpha | \leq 1\right\}\).

Lemma 25 (Spectrum of an isometry) Let \(T\) be an isometry on a Hilbert space, and \(T\) is not unitary. Then \[ \sigma (T)=\left\{ \alpha \in \mathbb {F}:|\alpha | \leq 1\right\} . \]

7.1 Orthonormal bases consisting of eigenvectors

Let us begin this section with the following useful lemma.

Lemma 27 (\(T^{*} T-\left\| T\right\|^{2} I\) is not invertible) If \(T\) is a bounded operator on a nonzero Hilbert space, then \(\left\| T\right\|^{2} \in \sigma \left(T^{*} T\right)\).

The following result points to one of the ways in which self-adjoint compact operators behave like self-adjoint operators on finite-dimensional Hilbert spaces.

Lemma 28 (Every self-adjoint compact operator has an eigenvalue) Let \(T\) be a self-adjoint compact operator on a nonzero Hilbert space. Then either \(\left\| T\right\|\) or \(-\left\| T\right\|\) is an eigenvalue of \(T\).

If \(T\) is an operator on a vector space \(V\), and \(U\) is a subspace of \(V\), then \(\left.T\right|_{U}\) is a linear map from \(U\) to \(V\). For \(\left.T\right|_{U}\) to be an operator (that is, a linear map from a vector space into itself), we need \(T(U) \subseteq U\). Thus, we arrive at the following definition.

Let \(T\) be an operator on a vector space \(V\). A subspace \(U\) of \(V\) is called an invariant subspace for \(T\) if \(T f \in U\) for every \(f \in U\).

Operators for which there exists an orthonormal basis consisting of eigenvectors may be the simplest operators to understand. The following result states that any such operator must be self-adjoint in the case of a real Hilbert space and normal in the case of a complex Hilbert space.

Lemma 30 (An orthonormal basis of eigenvectors implies self-adjointness or normality) Let \(T\) be a bounded operator on a Hilbert space \(V\), and suppose there exists an orthonormal basis of \(V\) consisting of eigenvectors of the operator \(T\).

  1. If \(\mathbb {F}=\mathbb {R}\), then \(T\) is self-adjoint.

  2. If \(\mathbb {F}=\mathbb {C}\), then \(T\) is normal.

The following result is one of the main achievements of the theory of compact operators on Hilbert spaces. The result below applies to both real and complex Hilbert spaces. In the case of a real Hilbert space, the result below can be combined with 10.103(a) to obtain the following result: A compact operator on a real Hilbert space is self-adjoint if and only if there exists an orthonormal basis of the Hilbert space consisting of eigenvectors of the operator.

Theorem 7 (Spectral theorem for self-adjoint compact operators) Let \(T\) be a self-adjoint compact operator on a Hilbert space \(V\). Then (a) there exists an orthonormal basis of \(V\) consisting of eigenvectors of \(T\); (b) there exists a countable set \(\Omega\), an orthonormal family \(\left\{ e_{k}\right\}_{k \in \Omega }\) in \(V\), and a family \(\left\{ \alpha_{k}\right\}_{k \in \Omega }\) in \(\mathbb {R} \backslash \left\{ 0\right\}\) such that

\[ T f=\sum _{k \in \Omega } \alpha _{k} \left\langle f, e_{k} \right\rangle e_{k} \]

for every \(f \in V\).

A normal compact operator on a nonzero real Hilbert space may have no eigenvalues [consider, for example, the normal operator \(T\) of counterclockwise rotation by a right angle on \(\mathbb {R}^{2}\), defined by \(\left.T(x, y)=(-y, x)\right]\). However, the following result shows that normal compact operators on complex Hilbert spaces behave better. The key idea in the proof of this result is that on a complex Hilbert space the real and imaginary parts of a normal compact operator are commuting self-adjoint compact operators, which allows us to apply the spectral theorem for self-adjoint compact operators.

Theorem 8 (Spectral theorem for normal compact operators) Let \(T\) be a compact operator on a complex Hilbert space \(V\). Then there exists an orthonormal basis of \(V\) consisting of eigenvectors of \(T\) if and only if \(T\) is normal.

The following example demonstrates the power of the spectral theorem for normal compact operators. Finding the eigenvalues and eigenvectors of the normal compact operator \(\mathcal{V}-\mathcal{V}^{*}\) in the following example leads us to an orthonormal basis of \(L^{2}([0,1])\). A simple computation shows that the family \(\left\{ e_{k}\right\}_{k \in \mathbb {Z}}\), where \(e_{k}\) is defined as in 10.112, is an orthonormal family in \(L^{2}([0,1])\). The hard part of proving that \(\left\{ e_{k}\right\}_{k \in \mathbb {Z}}\) is an orthonormal basis of \(L^{2}([0,1])\) is to show that the closed linear span of this family equals \(L^{2}([0,1])\). However, the spectral theorem for normal compact operators (10.107) provides this information without any further work.

ExampleExample 17

An example of an orthonormal basis of eigenvectors

SolutionSolution

Let \(\mathcal{V}: L^{2}([0,1]) \rightarrow L^{2}([0,1])\) be the Volterra operator, defined as follows:

\[ (\mathcal{V} f)(x)=\int _{0}^{x} f \]

The operator \(\mathcal{V}\) is compact (see the paragraph after the proof of 10.70), but it is not normal. Since \(\mathcal{V}\) is compact, \(\mathcal{V}^{*}\) is also compact (by 10.73). Hence \(\mathcal{V}-\mathcal{V}^{*}\) is compact. Also, \(\left(\mathcal{V}-\mathcal{V}^{*}\right)^{*}=\mathcal{V}^{*}-\mathcal{V}=-\left(\mathcal{V}-\mathcal{V}^{*}\right)\). Since every operator commutes with its negative, we conclude that \(\mathcal{V}-\mathcal{V}^{*}\) is a compact normal operator. Since we want to apply the spectral theorem, for the rest of this example we take \(\mathbb {F}=\mathbb {C}\).

If \(f \in L^{2}([0,1])\) and \(x \in [0,1]\), then the formula for \(\mathcal{V}^{*}\) given by formula 10.16 shows that

\[ \left(\left(\mathcal{V}-\mathcal{V}^{*}\right) f\right)(x)=2 \int _{0}^{x} f-\int _{0}^{1} f \]

The right-hand side of the equation above is a continuous function of \(x\) whose value at \(x=0\) is the negative of its value at \(x=1\).

Differentiating both sides of the equation above and using the Lebesgue differentiation theorem (4.19), we see that

\[ \left(\left(\mathcal{V}-\mathcal{V}^{*}\right) f\right)^{\prime }(x)=2 f(x) \]

for almost every \(x \in [0,1]\). If \(f \in \operatorname {null}\left(\mathcal{V}-\mathcal{V}^{*}\right)\), then differentiating both sides of the equation \(\left(\mathcal{V}-\mathcal{V}^{*}\right) f=0\) shows that \(2 f(x)=0\) for almost every \(x \in [0,1]\); hence \(f=0\), and we conclude that \(\mathcal{V}-\mathcal{V}^{*}\) is injective (hence 0 is not an eigenvalue).

Suppose \(f\) is an eigenvector of \(\mathcal{V}-\mathcal{V}^{*}\) with eigenvalue \(\alpha\). Thus, \(f\) is in the range of \(\mathcal{V}-\mathcal{V}^{*}\), which, by 10.109, implies that \(f\) is continuous on [ 0,1 ], and, again by 10.109, implies that \(f\) is continuously differentiable on \((0,1)\). Differentiating both sides of the equation \(\left(\mathcal{V}-\mathcal{V}^{*}\right) f=\alpha f\), we obtain:

\[ 2 f(x)=\alpha f^{\prime }(x) \]

for all \(x \in (0,1)\). Hence, the function whose value at \(x\) equals \(e^{-(2 / \alpha ) x} f(x)\) has derivative 0 everywhere on \((0,1)\) and, thus, is a constant function. In other words,

\[ f(x)=c e^{(2 / \alpha ) x} \tag {10.110} \]

for some constant \(c \neq 0\). Since \(f \in \operatorname {range}\left(V-\mathcal{V}^{*}\right)\), we have \(f(0)=-f(1)\), which together with the equation above implies the existence of \(k \in \mathbb {Z}\) such that

\[ 2 / \alpha =i(2 k+1) \pi . \tag {10.111} \]

Substituting into 10.110 the value of \(2 / \alpha\) obtained in 10.111, we see that for \(k \in \mathbb {Z}\) one should define \(e_{k} \in L^{2}([0,1])\) as follows:

\[ e_{k}(x)=e^{i(2 k+1) \pi x} \tag {10.112} \]

Clearly \(\left\{ e_{k}\right\}_{k \in \mathbb {Z}}\) is an orthonormal family in \(L^{2}([0,1])\) [orthogonality can be checked by direct computation or via 10.57]. The preceding paragraph together with the spectral theorem for normal compact operators (10.107) implies that this orthonormal family is an orthonormal basis of \(L^{2}([0,1])\).

7.2 Singular value decomposition

The following result gives an important generalization of the spectral theorem to arbitrary compact operators, which need not be self-adjoint or normal. This generalization requires two orthonormal families, in contrast to the single orthonormal family in the usual spectral theorem.

Theorem 9 (Singular value decomposition) Let \(T\) be a compact operator on a Hilbert space \(V\). Then there exists a countable set \(\Omega\), orthonormal families \[ \left\{ e^{(1)}_k\right\} _{k \in \Omega } \qquad \text{ and } \qquad \left\{ e^{(2)}_k\right\} _{k \in \Omega } \] in \(V\), and a family \(\left\{ \alpha_{k}\right\}_{k \in \Omega }\) of positive numbers such that \[ Tf = \sum _{k \in \Omega } \alpha _{k} \cdot \left\langle f, e^{(1)}_{k} \right\rangle \cdot e^{(2)}_{k} \] for every \(f \in V\).

The orthonormal families \(\left\{ e^{(1)}_{k}\right\}_{k \in \Omega }\) and \(\left\{ e^{(2)}_{k}\right\}_{k \in \Omega }\) in the singular value decomposition are not uniquely determined by the operator \(T\). However, the positive numbers \(\left\{ \alpha_{k}\right\}_{k \in \Omega }\) are uniquely determined as the positive square roots of the positive eigenvalues of \(T^{*}T\). These positive numbers can be arranged in decreasing order (since, if there are infinitely many of them, they form a sequence with limit \(0\)). This procedure leads to the definition of singular values below.

Suppose \(T\) is a compact operator. Recall that the geometric multiplicity of a positive eigenvalue \(\alpha\) of the operator \(T^{*} T\) is defined as \(\operatorname {dim} \operatorname {null}\left(T^{*} T-\alpha I\right)\) [see 10.81]. This geometric multiplicity is the number of times \(\sqrt{\alpha }\) appears in the family \(\left\{ s_{k}\right\}_{k \in \Omega }\) corresponding to the singular value decomposition of the operator \(T\). By 10.82, this geometric multiplicity is finite.

We can now define the singular values of a compact operator \(T\), where we carefully list the square root of each positive eigenvalue of the operator \(T^{*} T\) as many times as its geometric multiplicity.

  • Suppose \(T\) is a compact operator on a Hilbert space. The singular values of \(T\), denoted \(s_{1}(T) \geq s_{2}(T) \geq s_{3}(T) \geq \cdots\), are the positive square roots of the positive eigenvalues of \(T^{*} T\), arranged in decreasing order, with each singular value \(s\) listed as many times as the geometric multiplicity of \(s^{2}\) as an eigenvalue of \(T^{*} T\).

  • If \(T^{*} T\) has only finitely many positive eigenvalues, then define \(s_{n}(T)=0\) for all \(n \in \mathbb {N}\) for which \(s_{n}(T)\) is not defined by the first item.

An example of singular values on a finite-dimensional Hilbert space

SolutionSolution

Define \(T: \mathbb {F}^{4} \rightarrow \mathbb {F}^{4}\) as follows:

\[ T\left(z_{1}, z_{2}, z_{3}, z_{4}\right)=\left(0,3 z_{1}, 2 z_{2},-3 z_{4}\right) . \]

A computation shows that

\[ \left(T^{*} T\right)\left(z_{1}, z_{2}, z_{3}, z_{4}\right)=\left(9 z_{1}, 4 z_{2}, 0,9 z_{4}\right) . \]

Thus, the eigenvalues of \(T^{*} T\) equal \(9, 4, 0\) and

\[ \operatorname {dim}\left(T^{*} T-9 I\right)=2 \quad \text{ and } \quad \operatorname {dim}\left(T^{*} T-4 I\right)=1 . \]

Taking the square roots of the positive eigenvalues of \(T^{*} T\) and then appending an infinite sequence of zeros, we see that the singular values of \(T\) equal \(3 \geq 3 \geq 2 \geq 0 \geq 0 \geq \cdots\).

Note that -3 and 0 are the only eigenvalues of \(T\). Thus, in this case the list of eigenvalues of \(T\) does not contain the number 2, which appears in the definition (and hence in the behavior) of \(T\), but the list of singular values of \(T\) does include 2.

The following result establishes an important relationship between \(K \in L^{2}(\mu \times \mu )\) and the singular values of the integral operator associated with \(K\).

Lemma 31 (Sum of the squares of the singular values of an integral operator) Let \(\mu\) be a \(\sigma\)-finite measure and \(K \in L^{2}(\mu \times \mu )\). Let \(T_K\) be the integral operator with kernel \(K\). Then \[ \left\| K\right\| _{L^{2}(\mu \times \mu )}^{2}=\sum _{n=1}^{\infty }\left(s_{n}\left(T_K\right)\right)^{2} . \]

  1. Find the singular values for the (normal) operator \(T = \mathcal{V} - \mathcal{V}^*\);

  2. Find \(\frac{1}{1^{2}}+\frac{1}{3^{2}}+\frac{1}{5^{2}}+\cdots\).

SolutionSolution
Enum-item(i)

In example 10.108 we saw that if \(e_{k}\) is defined by formula 10.112, then \(\left\{ e_{k}\right\}_{k \in \mathbb {Z}}\) is an orthonormal basis of \(L^{2}([0,1])\) and

\[ T e_{k}=\frac{2}{i(2 k+1) \pi } e_{k} \]

\[ T^{*} e_{k}=\frac{-2}{i(2 k+1) \pi } e_{k} \]

for each \(k \in \mathbb {Z}\). Hence,

\[ T^{*} T e_{k}=\frac{4}{(2 k+1)^{2} \pi ^{2}} e_{k} \]

for each \(k \in \mathbb {Z}\). After taking positive square roots of the eigenvalues, we see that the equation above shows that the singular values of \(T\) equal:

\[ \frac{2}{\pi } \geq \frac{2}{\pi } \geq \frac{2}{3 \pi } \geq \frac{2}{3 \pi } \geq \frac{2}{5 \pi } \geq \frac{2}{5 \pi } \geq \cdots , \]

where the first two singular values above come from taking \(k=-1\) and \(k=0\) in 10.119, the next two singular values above come from taking \(k=-2\) and \(k=1\), the next two singular values above come from taking \(k=-3\) and \(k=2\), and so on. Each singular value of \(T\) appears twice in the list of singular values above, since each eigenvalue of \(T^{*} T\) has geometric multiplicity 2.

Enum-item(ii)

Define \(K:[0,1] \times [0,1] \rightarrow \mathbb {R}\) as follows:

\[ K(x, y)= \begin{cases} 1 & \text{ if } x>y \\ 0 & \text{ if } x=y \\ -1 & \text{ if } x<y \end{cases} \]

Let \(\lambda\) be Lebesgue measure on \([0,1]\), and note that the integral operator \(T_{K}\) is the normal compact operator \(\mathcal{V}-\mathcal{V}^{*}\) on \(L^2[0,1]\), where \(\mathcal{V}\) is the Volterra operator.

It is easy to compute \(\left\| K\right\|_{L^{2}(\lambda \times \lambda )}=1\). We have

\[ 1=2 \sum _{k=0}^{\infty } \frac{4}{(2 k+1)^{2} \pi ^{2}} \]

Thus,

\[ \frac{1}{1^{2}}+\frac{1}{3^{2}}+\frac{1}{5^{2}}+\cdots =\frac{\pi ^{2}}{8} . \]
