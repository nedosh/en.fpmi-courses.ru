1 Examples of metric spaces

Definition 1 Let \(X \neq \varnothing\). A function \(\rho : X \times X \to [0, +\infty )\) is called a metric if for all \(x, y, z \in X\) the following axioms hold:

  1. Nonnegativity: \(\rho (x, y) \geq 0\), positive definiteness: \(\rho (x, y) = 0 \iff x = y\);

  2. Symmetry: \(\rho (x, y) = \rho (y, x)\);

  3. Triangle inequality: \(\rho (x, z) \leq \rho (x, y) + \rho (y, z)\).

The pair \((X, \rho )\) is called a metric space (abbreviated MS).

Let \(X \neq \varnothing\) be a linear space over \(\mathbb {F}\) (\(\mathbb {F} = \mathbb {R}\) or \(\mathbb {C}\)). A function \(\left\| \cdot \right\| : X \to \mathbb {R}\) is called a norm if for all \(x, y \in X\) and scalar \(\alpha\) the following axioms hold:

  1. Nonnegativity: \(\left\| x\right\| \geq 0\), positive definiteness: \(\left\| x\right\| = 0 \iff x = \overrightarrow {0}\);

  2. Homogeneity: \(\left\| \alpha x\right\| = |\alpha | \cdot \left\| x\right\|\)

  3. Triangle inequality: \(\left\| x + y\right\| \leq \left\| x\right\| + \left\| y\right\|\)

The pair \((X, \left\| \cdot \right\| )\) is called a normed space (abbreviated NS).

A norm generates a metric via the following rule: \(\rho (x, y) = \left\| x - y\right\|\). All the metric axioms hold in this case (check this).

Examples of normed spaces (which are also metric spaces with the induced metric):

  • \(\mathbb {R}^n\) with \(\left\| \vec{x}\right\|_{p} = \left( \sum_{i=1}^{n} |x_i|^p \right)^{1/p}\) for \(1 \leq p < \infty\) and \(\left\| \vec{x}\right\|_{\infty } = \max_{1 \leq i \leq n} |x_i|\).

  • \(L^p(X, \mathcal{F}, \mu )\), \(1 \leq p \leq \infty\). In particular, \(\ell^p(X) = L^p(X, 2^X, \# )\), where \(\#\) is counting measure.

  • \(C[a,b]\) with the sup-norm: \(\left\| f\right\|_{\infty } = \sup_{x \in [a, b]} |f(x)|\).

The discrete metric. For any nonempty set \(X\), the discrete metric \(\rho\) is defined as follows: \(\rho (x, y)=0\) if \(x=y\), and \(\rho (x, y)=1\) if \(x \neq y\). This metric is not generated by a norm (if \(X\) is a linear space), since the homogeneity property fails (\(\rho (2x, 0) = 1 \neq 2 \cdot \rho (x, 0)\)).

Definition 2 A map \(f\) from a metric space \((X, \rho )\) to a metric space \((Y, \sigma )\) is called an isometry if it maps \(X\) onto \(Y\) and for all \(x_1, x_2 \in X\),

\[ \sigma \left(f\left(x_1\right), f\left(x_2\right)\right)=\rho \left(x_1, x_2\right). \]

Two metric spaces are called isometric if there exists an isometry from one onto the other. Isometry is an equivalence relation between metric spaces. From the point of view of metric spaces, two isometric metric spaces are entirely identical, and the isometry amounts to nothing more than a renaming of the points and metrics.

An open set is a set in which every point belongs to it together with some open ball (of positive radius).

A closed set is a set whose complement is open.

The closed ball:

\[ \overline{B}_r(x_0) = \left\{ x \in X \; : \; \rho (x,x_0) \leq r\right\} \]

A closed ball is always a closed set.

Proposition 1 Let \(X\) be an MS, \(A \subset X\). The following conditions are equivalent:

  • \(A\) is closed, i.e., \(A^{\complement }\) is open;

  • \(A = \operatorname {cl}A\);

  • \(\partial A \subset A\);

  • …

Proposition 2 Let \(X\) be an MS. Topological properties of open and closed sets:

  1. \(X\), \(\varnothing\) are open, \(X\), \(\varnothing\) are closed;

  2. Open sets are closed under finite intersections, closed sets are closed under finite unions;

  3. Open sets are closed under arbitrary unions, closed sets are closed under arbitrary intersections.

We say that \(x_n \to x\) in the MS \(X\) if \(\rho (x_n, x) \to 0\).

The limit can only be one.

ExampleExample 1

Show that the following metrics induce the same convergent sequences in Euclidean space: \[ \begin{aligned} & \rho ^{*}(x, y) = \left|x_{1}-y_{1}\right|+\cdots +\left|x_{n}-y_{n}\right| \\ & \rho ^{+}(x, y) = \max \left\{ \left|x_{1}-y_{1}\right|, \ldots ,\left|x_{n}-y_{n}\right|\right\} . \end{aligned} \]

SolutionSolution

For all \(x, y \in \mathbb {R}^{n}\) we have \[ \rho ^{+}(x, y) \le \rho ^{*}(x, y) \le n \, \rho ^{+}(x, y) . \] Consequently, if a sequence \(\{ x^{(k)}\}\) converges to \(x\) in the metric \(\rho^*\), then \[ \rho ^{+}(x^{(k)}, x) \le \rho ^{*}(x^{(k)}, x) \to 0, \] so it also converges in the metric \(\rho^+\). Conversely, if \(\{ x^{(k)}\} \to x\) in \(\rho^+\), then \[ \rho ^{*}(x^{(k)}, x) \le n \, \rho ^{+}(x^{(k)}, x) \to 0. \] Hence both metrics induce the same convergent sequences.

ExampleExample 2

Find a metric on \(\mathbb {R}^{n}\) that does not induce the same convergent sequences as the metric induced by the Euclidean norm.

SolutionSolution

Consider the discrete metric \[ \rho (x, y) = \begin{cases} 0, & x = y, \\ 1, & x \neq y. \end{cases} \] In this metric, a sequence converges to \(x\) if and only if it is eventually constant and equal to \(x\). This differs from convergence in the Euclidean metric, so the discrete metric does not induce the same convergent sequences.

ExampleExample 3

Show that in a metric space, an open ball is an open set.

SolutionSolution

Let \(B(x, r) = \{ y \in X : \rho (x, y) < r\}\). Take \(y \in B(x,r)\) and set \(\varepsilon = r - \rho (x, y) > 0\). For any \(z\) with \(\rho (y,z) < \varepsilon\), by the triangle inequality we have \[ \rho (x, z) \le \rho (x, y) + \rho (y, z) < \rho (x, y) + \varepsilon = r, \] so \(z \in B(x,r)\). Hence \(B(x,r)\) is open.

ExampleExample 4

In a metric space \(X\), is it possible that for some \(r > 0\) and two distinct points \(u\) and \(v\) we have \(B(u, r) = B(v, r)\)? Is this possible in Euclidean space \(\mathbb {R}^{n}\)? Is it possible in a normed linear space?

SolutionSolution

  • In a general metric space this is possible. For example, let \(X = \{ a,b\}\) with \(\rho (a,b)=1\) and \(r=2\); then \(B(a,2) = B(b,2) = X\).

  • In Euclidean space \(\mathbb {R}^{n}\) this is impossible: if \(B(u,r)=B(v,r)\) and \(u \neq v\), set \(d = \| u-v\| > 0\), take \(\varepsilon \in (0, \min (r,d))\) and the point \(w = u + \frac{r-\varepsilon }{d}(u-v)\); then \(\| w-u\| = r-\varepsilon < r\), i.e., \(w \in B(u,r)\), but \(\| w-v\| = \| w-u\| + \| u-v\| = r - \varepsilon + d > r\) (the points \(v,u,w\) lie on a single ray in this order, and the norm is additive along the ray), a contradiction.

  • In any normed linear space the same argument as in the Euclidean case applies, so this is also impossible.

3 Continuous maps between metric spaces

A map \(f: X \to Y\) between two MSs is called continuous at a point \(x\) if …

The following three statements generalize the corresponding results for real-valued functions of a real variable, and their proofs largely coincide with the proofs for that special case.

Proposition 3 A map is continuous at a point \(\iff\) it is sequentially continuous at that point.

Proposition 4 A map is continuous on all of \(X\) \(\iff\) the preimage of every open set in \(Y\) is open in \(X\).

Proposition 5 The composition of two continuous maps is continuous.

A map \(f: (X,\rho ) \to (Y, \sigma )\) between two MSs is called uniformly continuous if …

A uniformly continuous map is continuous everywhere.

A map \(f: (X,\rho ) \to (Y, \sigma )\) between two MSs is called Lipschitz if …

A Lipschitz map is uniformly continuous.

ExampleExample 5

Give an example of a continuous map that is not uniformly continuous, and of a uniformly continuous map that is not Lipschitz.

SolutionSolution

Continuous but not uniformly continuous: \(f(x) = x^2\) on \(\mathbb {R}\). Uniformly continuous but not Lipschitz: \(f(x) = \sqrt{x}\) on \([0,1]\).

ExampleExample 6

Show that any map from a metric space (\(X, \rho\)) to a metric space (\(Y, \sigma\)) is continuous if \(\rho\) is the discrete metric.

SolutionSolution

If \(\rho\) is discrete, take \(\delta = 1/2\) for any \(\varepsilon >0\). Then \(\rho (x,y)<\delta\) means \(x=y\), hence \(\sigma (f(x),f(y))=0<\varepsilon\), and any map is continuous.

ExampleExample 7

Let \(z\) be a point in a metric space (\(X, \rho\)). Define a function \(f: X \rightarrow \mathbb {R}\) by \(f(x) = \rho (x, z)\). Show that \(f\) is uniformly continuous.

SolutionSolution

For any \(x,y \in X\), by the triangle inequality we have \[ \left|f(x) - f(y)\right| = \left|\rho (x,z)-\rho (y,z)\right| \leq \rho (x,y) \] so \(f\) is Lipschitz with constant \(1\), hence uniformly continuous.

4 Complete metric spaces

4.1 Cauchy sequences

A Cauchy sequence (also a fundamental sequence) is …

ExampleExample 8

In a metric space \(X\), show

  1. that a convergent sequence is a Cauchy sequence,

  2. that a Cauchy sequence is bounded.

SolutionSolution
Enum-item(1)

Let \(x_n \to x\). For every \(\varepsilon >0\) there exists \(N\) such that \(n\ge N \Rightarrow \rho (x_n,x)<\varepsilon /2\). Then for \(m,n\ge N\): \(\rho (x_n,x_m) \le \rho (x_n,x)+\rho (x_m,x)<\varepsilon\). Hence \(x_n\) is a Cauchy sequence.

Enum-item(2)

For a Cauchy sequence \(\{ x_n\}\) there exists \(N\) such that \(m,n\ge N \Rightarrow \rho (x_n,x_m)<1\). Then all \(x_n\) for \(n\ge N\) lie in the ball of radius \(1\) around \(x_N\), and the finite set of the first \(N-1\) terms is also bounded. Hence the whole sequence is bounded.

An MS is called complete if every Cauchy sequence in it converges to some element of the MS.

Examples of complete MSs:

  • \(\mathbb {R}^{n}\);

  • \(C[a,b]\) with the sup-metric (unless stated otherwise, we always assume that \(C[0,1]\) is equipped with the sup-metric);

  • \(L^p(X, \mathcal{F}, \mu )\), \(1 \leq p \leq \infty\), for any measure space \((X, \mathcal{F}, \mu )\). This statement is called the Riesz-Fischer theorem.

4.2 Subspaces of complete MSs

In general, a subspace of a complete MS need not be complete. However,

Proposition 6 Let \(X\) be a complete MS and \(E \subset X\) a subspace of it. \(E\) is complete \(\iff\) \(E\) is closed.

ExampleExample 9

Let \(\mathcal{D}\) be the subspace of \(C[-1,1]\) consisting of continuous functions \(f:[-1,1] \rightarrow \mathbb {R}\) that are differentiable on \((-1,1)\). Is \(\mathcal{D}\) complete?

Unless stated otherwise, \(C[-1,1]\) is equipped with the sup-metric (the metric of uniform convergence).

SolutionSolution

\(C[-1,1]\) is complete, so to check whether a subset of it is complete, it suffices to check whether it is closed.

The functions \(f_n(x)=\sqrt{x^2+1/n}\) are differentiable and converge uniformly to \(f(x)=|x|\), which is continuous but not differentiable at \(0\). That is, \(\mathcal{D}\) is not closed.

AnswerAnswer

No

ExampleExample 10

Define \(\mathcal{L}\) as the subspace of \(C[0,1]\) consisting of functions \(f:[0,1] \rightarrow \mathbb {R}\) that are Lipschitz. Is \(\mathcal{L}\) complete?

SolutionSolution

We need to check whether \(\mathcal{L}\) is closed in \(C[0,1]\).

  • Consider the function \(f(x) = \sqrt{x}\), and consider the sequence of functions

    \[ f_n(x) = \begin{cases} \sqrt{\frac{1}{n}}nx, & x < \frac{1}{n}\\ \sqrt{x}, & x \geq \frac{1}{n} \end{cases} \]

    That is, the graph of \(f_n\) is a line segment from \((0,0)\) to \(\left(\frac{1}{n}, \sqrt{\frac{1}{n}}\right)\), followed by the graph of the square root \(\sqrt{x}\).

  • It is clear that \(f_n\) converges to \(f\) pointwise. One can prove by hand, or use Dini’s theorem, that \(f_n\) converges uniformly to \(f\), i.e., in the norm of the space \(C[0,1]\).

  • \(f_n\) is Lipschitz for every \(n\) (this is a straightforward exercise), while \(f\) is not.

  • We conclude that \(\mathcal{L}\) is not closed.

AnswerAnswer

No.

ExampleExample 11

Define \(\mathcal{L}_3\) as the subspace of \(C[0,1]\) consisting of functions \(f:[0,1] \rightarrow \mathbb {R}\) that are Lipschitz with one and the same constant (in this case, \(3\)): \[ \mathcal{L}_3 = \left\{ f \in C[0,1] \; : \; \left|f(x) - f(y)\right| \leq 3 \cdot \left|x-y\right|, \; \forall x,y \in [0,1]\right\} \] Is \(\mathcal{L}_3\) complete?

SolutionSolution

A uniform (or even pointwise) limit of Lipschitz functions with one and the same constant will be Lipschitz with the same constant. Indeed, let \(f_n \in \mathcal{L}_3\), \(f_n \xrightarrow []{\rho }f\). Then \[ \begin{align} \left|f(x) - f(y)\right| & \leq \left|f(x) - f_n(x)\right| + \left|f_n(x) - f_n(y)\right| + \left|f_n(y) - f(y)\right| \\ & \leq \left|f(x) - f_n(x)\right| + 3 \cdot \left|x-y\right| + \left|f_n(y) - f(y)\right| \xrightarrow [n \to \infty ]{} 3 \cdot \left|x-y\right| \end{align} \] That is, \(\mathcal{L}_3\) is closed in \(C[0,1]\).

AnswerAnswer

Yes.

4.3 Completion of an incomplete MS

Theorem 1 (on completion) Let \((X,\rho )\) be an MS. Then there exists a complete MS \((\hat{X}, \sigma )\) such that \(X\) is dense in \(\hat{X}\) (more precisely, \(X\) can be isometrically mapped into some subset \(\tilde{X} \subset \hat{X}\) that is dense in \(\hat{X}\)) and \[ \rho (u,v) = \sigma (u,v), \qquad \forall u,v \in X \]

The complete MS \((Y, \sigma )\) described above is called the completion of \((X,\rho )\). The completion is unique in the sense that any two completions are isometric via an isometry that is the identity map on \(X\).

Mn-proofProof

4.4 Proof sketch

  1. If \(\left\{ x_{n}\right\}\) and \(\left\{ y_{n}\right\}\) are Cauchy sequences in \(X\), one needs to show that \(\left\{ \rho (x_{n}, y_{n})\right\}\) is a Cauchy sequence in \(\mathbb {R}\) and hence converges.

  2. Define \(X^{\prime }\) as the set of Cauchy sequences in \(X\). For two Cauchy sequences \(\left\{ x_{n}\right\}\) and \(\left\{ y_{n}\right\}\), define \(\rho^{\prime }(\left\{ x_{n}\right\} ,\left\{ y_{n}\right\} ) = \lim \rho (x_{n}, y_{n})\).

  3. Define two sequences \(\left\{ x_{n}\right\}\) and \(\left\{ y_{n}\right\}\) in \(X^{\prime }\) to be equivalent if \(\rho^{\prime }(\left\{ x_{n}\right\} ,\left\{ y_{n}\right\} ) = 0\). One needs to show that this is an equivalence relation. Denote by \(\widehat{X}\) the set of equivalence classes. Define the distance \(\widehat{\rho }\) between classes as \(\rho^{\prime }\) between representatives of the classes. One needs to show that \(\widehat{\rho }\) is well defined and is a metric on \(\widehat{X}\).

  4. One needs to show that the metric space \((\widehat{X}, \widehat{\rho })\) is complete.

    Hint: If \(\left\{ x_{n}\right\}\) is a Cauchy sequence from \(X\), one may assume [by passing to a subsequence] that \(\rho (x_{n}, x_{n+1}) < 2^{-n}\) for all \(n\). If \(\left\{ \{ x_{n, m}\}_{n = 1}^{\infty }\right\}_{m = 1}^{\infty }\) is a sequence of such Cauchy sequences representing a Cauchy sequence in \(\widehat{X}\), then the diagonal sequence \(\left\{ x_{n, n}\right\}_{n = 1}^{\infty }\) is a Cauchy sequence in \(X\) representing the limit of the Cauchy sequences from \(\widehat{X}\).

  5. Define a map \(h\) from \(X\) to \(\widehat{X}\) by assigning to each \(x \in X\) the equivalence class of the constant sequence all of whose terms equal \(x\). One needs to show that \(h(X)\) is dense in \(\widehat{X}\) and that \(\widehat{\rho }(h(u), h(v)) = \rho (u, v)\) for all \(u, v \in X\).

  6. Define the set \(\widetilde{X}\) as the disjoint union of \(X\) and \(\widehat{X} \setminus h(X)\). For \(u, v \in \widetilde{X}\), define \(\widetilde{\rho }(u, v)\) as follows: \(\widetilde{\rho }(u, v) = \rho (u, v)\) if \(u, v \in X\); \(\widetilde{\rho }(u, v) = \widehat{\rho }(u, v)\) if \(u, v \in \widehat{X} \setminus h(X)\); and \(\widetilde{\rho }(u, v) = \widehat{\rho }(h(u), v)\) for \(u \in X, v \in \widehat{X} \setminus h(X)\). From the previous parts it follows that the metric space (\(\widetilde{X}, \widetilde{\rho }\)) is complete and contains (\(X, \rho\)) as a dense subspace.

5 Compact metric spaces

Proposition 7 (Equivalence of various definitions of compactness for metric spaces) Let \(X\) be a metric space. The following conditions are equivalent:

  1. \(X\) is compact: every open cover of \(X\) has a finite subcover;

  2. \(X\) is sequentially compact: every sequence in \(X\) has a subsequence that converges to a point of \(X\);

  3. \(X\) is countably compact: every countable open cover of \(X\) has a finite subcover;

  4. \(X\) is limit point compact: every infinite subset of \(X\) has a limit point in \(X\);

  5. \(X\) is pseudocompact: every continuous function \(f: X \to \mathbb {R}\) is bounded;

5.1 A generalization of the Bolzano-Weierstrass theorem: a compactness criterion for an arbitrary metric space

Let us recall the compactness criterion in \(\mathbb {R}^{n}\) (and, in essence, in any finite-dimensional normed space over \(\mathbb {R}\), since it is always isomorphic to \(\mathbb {R}^{n}\)).

Theorem 2 (Bolzano-Weierstrass) Let \(X = \mathbb {R}^{n}\) with the standard Euclidean metric. Let \(A \subset \mathbb {R}^{n}\). \(A\) can be regarded as a subspace of the metric space \(\mathbb {R}^{n}\). Then \[ A \text{ is compact} \iff A \text{ is closed (in $\mathbb {R}^{n}$) and bounded} \]

Let us try to obtain a compactness criterion for an arbitrary MS. The closedness condition loses its meaning in this case, since every space is closed (in itself). It should be replaced by completeness. In fact, since \(\mathbb {R}^{n}\) is complete, a subspace of it is closed if and only if it is complete. Hence, in the Bolzano-Weierstrass theorem, closedness in \(\mathbb {R}^{n}\) can be replaced by completeness.

Let us now discuss boundedness. An arbitrary metric space \(X\) is bounded if it lies entirely within some ball of finite radius. Equivalently: an MS is bounded if its diameter is finite:

\[ \operatorname {diam}X = \sup _{x_1,x_2 \in X} \rho (x_1,x_2) < \infty \]

It turns out that compactness implies boundedness. However, boundedness (together with completeness) is in general not sufficient for compactness.

ExampleExample 12

Show that the closed unit ball centered at the zero vector (the zero sequence) in \(\ell^2\) is a complete and bounded subspace, but is not compact.

Recall that \(\ell^2\) is the linear space of square-summable sequences \[ \ell ^2 = \left\{ x = (x_n)_{n \in \mathbb {N}} \; : \; x_n \in \mathbb {R}, \; \sum _{n=1}^{\infty }\left|x_n\right|^2 < \infty \right\} \] The norm on this space: \(\left\| x\right\|_{2} := \sqrt{\sum_{n=1}^{\infty }\left|x_n\right|^2 }\).

SolutionSolution

Denote for brevity \(\bar{B} := \bar{B}_1(0)\).

  • Note that \(\ell^2 = L^{2}(\mathbb {N}, 2^{\mathbb {N}}, \# )\), where \(\#\) is counting measure. That is, \(\ell^2\) is a special case of a Lebesgue space. For \(L^p\) spaces, it is known that they are complete. Hence \(\ell^2\) is complete.

  • A closed ball is always a closed set. \(\ell^2\) itself is complete, and, as we know, in a complete space closedness of a subset is equivalent to its completeness. Hence \(\bar{B}\) is a complete subspace.

  • \(\bar{B}\) is clearly bounded.

  • Consider the vectors \(e^{(i)} \in \ell^2\), \(i \in \mathbb {N}\): \(e^{(i)}\) has \(1\) in the \(i\)-th position and \(0\) elsewhere. This is a sequence of points from \(\bar{B}\), and the distance between any two of them equals \(\sqrt{2}\). That is, it is impossible to find a convergent subsequence among them. Hence \(\bar{B}\) is not sequentially compact, and therefore not compact.

As the example shows, compactness requires a stronger condition than ordinary boundedness.

By an \(\varepsilon\)-net for a metric space \(X\) we mean a finite collection of open balls \(\left\{ B_{\varepsilon }\left(x_k\right)\right\}_{k=1}^n\) centered at \(x_k \in X\) that covers \(X\). A metric space \(X\) is said to be totally bounded if for every \(\epsilon >0\) there exists an \(\epsilon\)-net for \(X\).

If a metric space \(X\) is totally bounded, then it is bounded in the sense that its diameter is finite. Indeed, if \(X\) is covered by finitely many balls of radius \(r\), then by the triangle inequality \(\operatorname {diam} X \leq c\), where \(c = 2 \cdot r + d\), and \(d\) is the maximum distance between the centers of the covering balls. However, as the following example shows, a bounded metric space need not be totally bounded.

SolutionSolution

Theorem 3 (Compactness criterion for an MS) Let \(X\) be a metric space. \[ X \text{ is compact} \iff X \text{ is complete and totally bounded} \]

In finite-dimensional normed spaces, a bounded set is always totally bounded.

The difference between the notions shows up in infinite-dimensional normed spaces. As we will prove later, the following theorem holds.

  3. by showing that \(\bar{B}\) is not totally bounded.

SolutionSolution
Enum-item(1)

Consider the vectors (sequences) \(e^{(n)}\), which have \(1\) in position \(n\) and \(0\) elsewhere. Each \(e^{(n)} \in \bar{B}\), but no subsequence converges in \(\ell^{2}\). Indeed, if one did, it would be a Cauchy sequence. But the distance between any two vectors of the sequence equals \(\sqrt{2}\). That is, no Cauchy subsequence can be found among them. Thus \(\bar{B}\) is not sequentially compact.

Enum-item(2)

We need to find an open cover of \(\bar{B}\) with no finite subcover. Consider the open sets \(U_0 = \ell^2 \setminus \left\{ e^{(n)}\right\}_{n \in \mathbb {N}}\) and \(U_n = B_1\left(e^{(n)}\right)\), \(n \in \mathbb {N}\).

  • \(\left\{ U_n\right\}_{n \geq 0}\) covers \(\bar B\): the points of \(\bar B \setminus \left\{ e^{(n)}\right\}_n\) lie in \(U_0\), and the point \(e^{(n)}\) itself lies in its own \(U_n\).

Enum-item(3)

Let \(\varepsilon < \frac{\sqrt{2}}{2}\) be arbitrary. As already shown above, \(\bar{B}\) contains an infinite collection of vectors whose pairwise distances all exceed \(2 \varepsilon\). By the triangle inequality, it is impossible to find a (finite) \(\varepsilon\)-net for \(\bar{B}\).

6 Separable metric spaces

Let \(X\) be an MS. \(D \subset X\) is called dense if …

An MS is called separable if it has a countable dense subset.

Examples of separable MSs:

  • \(\mathbb {R}^{n}\) for any \(n\);

  • The Weierstrass approximation theorem (the Stone-Weierstrass theorem) says that any function from \(C[0,1]\) can be approximated arbitrarily closely by a polynomial. Any polynomial can be approximated arbitrarily closely on \([0,1]\) by a polynomial with rational coefficients. Thus \(C[0,1]\) is separable: a countable dense system is given by the polynomials with rational coefficients.

  • For \(1 \leq p < \infty\), the space \(L^p[0,1]\) is separable. \(L^{\infty }[0,1]\) is not separable.

Proposition 12 A compact MS is always separable.

Proposition 13 An MS is separable \(\iff\) it satisfies the second axiom of countability: it has a countable neighborhood base (i.e., there exists a countable collection \(\left\{ \mathcal{O}_n\right\}_{n \in \mathbb {N}}\) of open subsets of \(X\) such that any other open subset of \(X\) can be represented as a union of a subcollection of \(\left\{ \mathcal{O}_n\right\}_{n \in \mathbb {N}}\)).

For example, if \(X = \mathbb {R}^{n}\), then a countable neighborhood base is given by the open balls with rational radii and centers at rational points.

Proposition 14 Any subspace of a separable MS is necessarily separable.

This statement is not as obvious as it might seem at first glance, since if \(X\) is a space, \(D \subset X\) is dense and countable, and \(A \subset X\) is a subspace, it is not enough to simply take the intersection \(A \cap D\) and claim that it will be a countable dense subset of \(A\). For example, \(X = \mathbb {R}\) is separable: \(D = \mathbb {Q}\) is a countable dense subset of it. Then, by the statement, the subspace of irrational numbers \(A = \mathbb {R} \setminus \mathbb {Q}\) will also be separable, even though \(A \cap D = \varnothing\).

ExampleExample 15

Let \(X\) be a metric space containing a finite dense subset \(D\). Show that \(X = D\).

SolutionSolution

Suppose \(D = \{ d_{1},\dots ,d_{n}\}\) is dense in \(X\). If there exists \(x \in X \setminus D\), consider \[ \delta = \min _{1\leq i \leq n} \rho (x,d_{i}) > 0 . \] Then the ball \(B(x,\delta /2)\) contains \(x\) but contains none of the points \(d_{i}\), which contradicts the density of \(D\). Hence no such \(x\) exists and \(X=D\).

7 The contraction mapping principle

Definition 4 A point \(x\) in \(X\) is called a fixed point of a map \(T: X \rightarrow X\) if \(T(x)=x\).

In this section we seek conditions on a map that guarantee the existence of a fixed point. For a real function of one variable, this corresponds to the intersection of its graph with the diagonal \(y=x\). From this the first result follows easily: if \(f:[a,b]\to \mathbb {R}\) is continuous and \(f([a,b])\subseteq [a,b]\), then \(f\) has a fixed point. Indeed, setting \(g(x)=f(x)-x\), we get \(g(a)\geq 0\), \(g(b)\leq 0\), so by the intermediate value theorem \(g(x_0)=0\) for some \(x_0\in [a,b]\), that is, \(f(x_0)=x_0\).

In the multidimensional case, a generalization holds: if \(K\subset \mathbb {R}^n\) is a compact convex set and \(T:K\to K\) is continuous, then \(T\) has a fixed point. This is Brouwer’s fixed point theorem.

In this section we will prove a different result — the Banach contraction mapping principle. It requires a more restrictive condition on the map, but allows a very general space.

Let us recall the definition.

Definition 5 A map \(T\) of a metric space \((X, \rho )\) into itself is called Lipschitz if there exists a number \(c \geq 0\), called the Lipschitz constant of the map, such that \[ \rho (T(u), T(v)) \leq c \rho (u, v) \quad \text{for all } u, v \in X. \] If \(c<1\), the Lipschitz map is called a contraction.

Theorem 5 (The Banach contraction mapping principle) Let \(X\) be a complete metric space, and let the map \(T: X \rightarrow X\) be a contraction. Then \(T: X \rightarrow X\) has exactly one fixed point.

Mn-proofProof

Let \(c\) be a number in \([0, 1)\) that is a Lipschitz constant for the map \(T\).

  • Choose a point in \(X\) and denote it \(x_{0}\). Define a sequence \(\{ x_{k}\}\) inductively: \(x_{k+1}=T(x_{k})\). We will show that this sequence converges to a fixed point of \(T\).

  • Indeed, note that for each \(k\)

    \[ \rho (x_{k+1}, x_{k}) = \rho (T(x_{k}), T(x_{k-1})) \leq c \rho (x_{k}, x_{k-1}), \]

    and hence, by induction,

    \[ \rho (x_{k+1}, x_{k}) \leq c^{k} \rho (T(x_{0}), x_{0}). \]

    Consequently, by the triangle inequality and the formula for the sum of a geometric series, for \(m>k\)

    \[ \begin{align} \rho (x_{m}, x_{k}) & \leq \rho (x_{m}, x_{m-1}) + \rho (x_{m-1}, x_{m-2}) + \cdots + \rho (x_{k+1}, x_{k}) \\ & \leq \left[c^{m-1} + c^{m-2} + \cdots + c^{k}\right] \rho (T(x_{0}), x_{0}) \\ & = c^{k}\left[1 + c + \cdots + c^{m-1-k}\right] \rho (T(x_{0}), x_{0}) \\ & = c^{k} \cdot \frac{1 - c^{m-k}}{1 - c} \cdot \rho (T(x_{0}), x_{0}). \end{align} \]

  • Thus, since \(0 \leq c < 1\),

    \[ \rho (x_{m}, x_{k}) \leq \frac{c^{k}}{1 - c} \cdot \rho (T(x_{0}), x_{0}) \quad \text{for } m > k. \]

    But \(\lim_{k \to \infty } c^{k} = 0\), and hence the previous inequality shows that \(\{ x_{k}\}\) is a Cauchy sequence.

  • By assumption, the metric space \(X\) is complete, so there exists a point \(x \in X\) to which the sequence \(\{ x_{k}\}\) converges. Since \(T\) is Lipschitz, it is continuous. It follows that

    \[ T(x) = \lim _{k \to \infty } T(x_{k}) = \lim _{k \to \infty } x_{k+1} = x. \]

    Hence the map \(T: X \rightarrow X\) has at least one fixed point.

  • It remains to check that the fixed point is unique. But if \(u\) and \(v\) are points in \(X\) such that \(T(u)=u\) and \(T(v)=v\), then

    \[ 0 \leq \rho (u, v) = \rho (T(u), T(v)) \leq c \rho (u, v), \]

    so, since \(0 \leq c < 1\), we have \(\rho (u, v) = 0\), i.e., \(u = v\). \(\square\)

The proof of the contraction mapping principle given above provides substantially more than just a proof of the existence of a unique fixed point. It includes an algorithm for finding the fixed point. Indeed, if one takes an arbitrary point \(x_{0} \in X\) and recursively defines the sequence \(x_{k+1}=T(x_{k})\) for \(k \geq 0\), then this sequence converges to the fixed point \(x_{*}\) of \(T\), and moreover at an exponential rate (the distance to \(x_*\) decreases exponentially):

\[ \rho (x_{*}, x_{k}) \leq \frac{c^{k}}{1 - c} \rho (T(x_{0}), x_{0}). \]

8 Compactness in the space of continuous functions on a compact set: the Arzelà-Ascoli theorem

Let \(C[0,1]\) be the space of continuous real-valued functions on the interval \([0,1]\) with the norm

\[ \| f\| _\infty =\max _{x\in [0,1]}|f(x)|. \]

Let us recall the definitions.

Uniform boundedness. A family of functions \(\mathcal F\subset C[0,1]\) is called uniformly bounded if there exists \(M<\infty\) such that for all \(f\in \mathcal F\) and all \(x\in [0,1]\) we have \(|f(x)|\le M\).

Equicontinuity. A family \(\mathcal F\) is called equicontinuous if

\[ \forall \varepsilon >0\ \exists \delta >0\ \forall f\in \mathcal F\ \forall x,y\in [0,1]:\ |x-y|<\delta \Rightarrow |f(x)-f(y)|<\varepsilon . \]

Theorem 6 (Arzelà-Ascoli in \(C[0,1]\)) For a family \(\mathcal{F} \subset C[0,1]\), the following conditions are equivalent:

  1. \(\mathcal{F}\) is relatively compact in \(C[0,1]\), i.e., its closure is compact (or, equivalently, \(\mathcal{F}\) is totally bounded).

  2. \(\mathcal{F}\) is uniformly bounded and equicontinuous on \([0,1]\).

8.1 Corollaries and remarks

  • It follows from the theorem that if a sequence of functions \((f_n)\) is uniformly bounded and equicontinuous, then a subsequence of it can be extracted that converges uniformly on \([0,1]\).

  • The statement and proof carry over to the space of continuous functions with the metric topology of a compact metric space in place of \([0,1]\).
